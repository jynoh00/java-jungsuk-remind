# 07. 예외 되던지기
> 예외 되던지기(`exception re-throwing`)는 예외를 처리한 후 인위적으로 다시 발생시킴으로 구현된다

앞서 한 메서드에서 발생할 수 있는 예외가 여럿일 경우, 몇 개는 `try-catch`를 통해 자체적으로 처리하고<br>
나머지는 선언부에 지정하여 호출한 메서드에서 처리하도록 함으로 양쪽에서 나눠 처리되게 할 수 있었다.

⭐ 단 하나의 예외에 대해서도 예외가 발생한 메서드와 호출한 메서드, 양쪽에서 처리하도록 할 수 있다.

하나의 예외에 대해서 예외가 발생한 메서드와 이를 호출한 메서드 양쪽 모두에서 처리해줘야 할 작업 있을 때 사용된다.<br>
이때 `exception re-throwing` 시 다음을 주의해야 한다.

- 예외가 발생할 메서드에서는 `try-catch`문을 사용, 예외처리를 해줌과 동시에
- 메서드 선언부에 발생할 예외를 `throws`에 지정해줘야 한다.

---

```java
public static void main(String[] args) {
    try {
        method1();
    } catch (Exception e) {
        System.out.println("exception handling in main()");
    }
}

static void method1() throws Exception {
    try {
        throw new Exception();
    } catch (Exception e) {
        System.out.println("exception handling in method1()");
        throw e;
    }
}
```

`method1()` 내 `try`블럭에서 발생시킨 `Exception` 객체를 `catch`블럭에서 처리한다.<br>
이후 다시 동일 객체를 `throw` 해주어 `main`메서드에서 `try-catch`문을 통해 동일 `Exception`을 처리한다.

---

추가로 반환값이 있는 `return`문의 경우, `catch`블럭에도 `return`문이 있어야 한다.<br>
예외가 발생했을 경우에도 반환 값이 존재해야 하기 때문이다.

```java
static int method1() {
    try {
        System.out.println("method1() run");
        return 0;
    } catch (Exception e) {
        e.printStackTrace();
        return 1;
    } finally {
        System.out.println("method1() finally run");
    }
}
```

혹은 `catch`블럭에서 예외 되던지기를 해서 호출한 메서드로 예외를 전달한다면<br>
`return`문이 존재하지 않아도 된다.

```java
static int method1() throws Exception {
    try {
        System.out.println("method1() run");
        return 0;
    } catch (Exception e) {
        e.printStackTrace();
        throw e;
    } finally {
        System.out.println("method1() finally run");
    }
}
```

( `finally`블럭 내에도 `return`문을 사용할 수 있으며, `try`블럭이나 `catch`블럭의 `return`문 다음에 수행 )<br>
( 최종적으로 `finally`블럭 내의 `return`문의 값이 반환된다 )
