# 03. 고의적 예외 발생

키워드 `throw`를 사용하여 프로그래머가 고의로 예외를 발생시킬 수 있으며 방법은 아래와 같다.

1. 연산자 `new`로 발생시키려는 예외 클래스의 객체 생성

```java
Exception e = new Exception("고의 발생 예외");
```

2. 키워드 `throw`를 이용해서 예외를 발생시킨다. (예외를 던진다)

```java
throw e;
```

```java
class ExceptionEx {
    public static void main(String[] args) {
        try {
            Exception e = new Exception("고의 발생 예외");
            throw e; // 예외를 발생시킨다.
        } catch (Exception e) {
            System.out.println(e.getMessage());
            e.printStackTrace();
        }
        
        System.out.println("정상 종료");
    }
}
```

`Exception` 인스턴스를 생성할 때, 생성자에 문자열을 넣어주면 이 문자열이 `Exception`인스턴스에 메시지로 저장된다.<br>
해당 문자열은 `e.getMessage()`를 이용해서 얻을 수 있다.

---

```java
class ExceptionEx {
    public static void main(String[] args) {
        throw new Exception();
    }
}
```

위 예제를 작성한 후 컴파일하면 아래와 같은 결과를 얻는다.

```shell
java: unreported exception java.lang.Exception; must be caught or declared to be thrown
```

에러가 발생하며 컴파일되지 않는다.

예외 처리가 필요한 부분에 예외 처리가 되어 있지 않다는 에러이다.<br>
`Exception`클래스들이 발생할 가능성이 있는 문장들에 대해 예외 처리를 해주지 않으면 컴파일조차 되지 않는 것이다.

```java
class ExceptionEx {
    public static void main(String[] args) {
        throw new RuntimeException();
    }
}
```

```shell
Exception in thread "main" java.lang.RuntimeException
at ch08.ExceptionEx.main(ExceptionEx.java:5)
```

반면 `RuntimeException`의 경우 이전과 같이 예외 처리를 하지 않았음에도 성공적으로 컴파일된다.<br>
그러나 실행하면 위 실행결과처럼 `RuntimeException`이 발생하여 비정상 종료된다.

이를 통해 앞서 `01.예외 클래스.md`에서 알아본 `RuntimeException`클래스와<br>
⭐ 그 자손들에 해당하는 예외는 프로그래머에 의해 실수로 발생하는 것들이기 때문에 예외처리를 강제하지 않는 것이다.<br>
⭐ ( 즉, 런타임예외가 아닌 예외는 컴파일부터 에러를 일으켜 예외처리를 강제한다는 것이다 )

---

만일 `RuntimeException`클래스들에 속하는 예외가 발생할 가능성이 있는 코드에도 예외처리를 강제 해야 한다면

아래와 같이 참조 변수와 배열이 사용되는 모든 곳에 예외 처리를 해주어야 할 것이다.<br>
(`NullPointerException`, `ArrayIndexOutOfBoundsException`은 `RuntimeException`의 자손이기에)

```java
try {
    int[] arr = new int[10];
    ...
    System.out.println(arr[i]);
} catch (...) {
    ...
} catch (...) {
    ...    
}
```

⭐ 컴파일러가 예외처리를 확인하지 않는 `RuntimeException`클래스들은 `unchecked예외`라 부르며<br>
⭐ 예외처리를 확인하는 `Exception`클래스들을 `checked예외`라 부른다.
