# 05. finally
> `finally`블럭은 예외 발생 여부에 상관없이 실행되어야 하는 코드를 포함시킬 목적으로 사용된다

`try-catch`문 끝에 선택적으로 덧붙여 사용 가능하며, `try-catch-finally`순으로 구성된다.

```java
try {
    ...    
} catch (ExceptionA e) {
    ...
} finally {
    ...
}
```

---

아래 예시는 `finally`블럭을 사용하지 않은 경우의 예외처리 예제이다.

```java
...
try {
    startInstall();
    copyFiles();
    deleteTempFiles();
} catch (Exception e) {
    e.printStackTrace();
    deleteTempFiles();
}
...
```

`startInstall`, `copyFiles`, `deleteTempFiles` 메서드는 각 의미에 해당하는 작업을 수행하는 코드가<br>
작성되어 있다고 가정한다.

프로그램 설치를 위한 준비를 하고(`startInstall()`) 파일들을 복사한 후(`copyFiles()`)<br>
설치가 완료되면 프로그램 설치 시 사용된 임시 파일들을 삭제하는(`deleteTempFiles()`) 순서로 진행된다.

코드를 살펴보면 결국 예외의 발생 여부와 관계없이 `deleteTempFiles()` 메서드는 반드시 실행되어야 한다.

이럴 때 `finally`블럭을 사용해 아래처럼 수정할 수 있다.

```java
try {
    startInstall();
    copyFiles();
} catch (Exception e) {
    e.printStackTrace();
} finally {
    deleteTempFiles();
}
...
```

---

```java
class FinallyEx {
    public static void main(String[] args) {
        FinallyEx.method1();
        System.out.println("method1() 종료, main()메서드");
    }
    
    static void method1() {
        try {
            System.out.println("method1() 호출");
            return;
        } catch (Exception e) {
            e.printStackTrace();
        } finally {
            System.out.println("method1()의 finally블럭 실행");
        }
    }
}
```

```shell
method1() 호출
method1()의 finally블럭 실행
method1() 종료, main()메서드
```

⭐ 위 결과를 통해 알 수 있듯이 `try`블럭에서 `return`문이 실행되는 경우에도 `finally`블럭의 문장들이<br>
먼저 실행된 후에 현재 실행 중인 메서드를 종료한다.

⭐ 마찬가지로 `catch`블럭의 수행 중에 `return`문을 만나도 `finally`블럭의 문장들은 수행된다.
