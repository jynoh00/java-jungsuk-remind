# 02. 예외 처리
> 예외 처리 (`Exception handling`)란, 프로그램 실행 시 발생할 수 있는 예기치 못한 예외에 대비한 코드 작성

예외처리의 목적은, 예외의 발생으로 인한 실행 중인 프로그램의 비정상 종료를 막고, 정상 실행상태를 유지하는 것이다.

( 에러와 예외는 모두 실행 시 (`runtime`) 발생할 수 있는 오류이다 )<br>
⭐ ( 실행 중 발생하는 에러는 어쩔 수 없지만, 예외는 미리 처리할 수 있으며 해야한다 )

⭐ 발생한 예외를 처리하지 못하면, 프로그램은 비정상 종료된다.<br>
처리되지 못한 예외(`uncaught exception`)는 JVM의 예외 처리기(`UncaughtExceptionHandler`)가 받아서<br>
예외의 원인을 화면에 출력한다.

---

```java
// 기본적 예외 처리 try-catch문 구조

try {
    // 예외가 발생할 가능성이 있는 문장들    
} catch (Exception1 e1) {
    // Exception1이 발생할 경우, 이를 처리하기 위한 문장
} catch (Exception2 e2) {
    // Exception2가 발생할 경우, 이를 처리하기 위한 문장
} catch (ExceptionN eN){
    // ExceptionN이 발생할 경우, 이를 처리하기 위한 문장
}
```

`try`블럭에서 예외가 발생하면, `catch`블럭에서 발생한 예외의 종류와 일치하는 단 하나의 `catch`블럭만 수행된다.<br>
발생한 예외의 종류와 일치하는 `catch`블럭이 없으면 예외는 처리되지 않는다.

예외가 발생하면 예외 객체가 생성되는데, 이 객체에 예외의 정보가 있으며 `catch`블럭에 선언된<br>
참조변수를 통해서 접근할 수 있다.

---

`try-catch`문에서 예외가 발생한 경우와 발생하지 않았을 때의 실행 흐름은 아래와 같다.

1. 예외가 발생한 경우
   1. 발생한 예외와 일치하는 `catch`블럭이 있는지 찾는다.
   2. 일치하는 `catch`블럭을 찾으면, 해당 `catch`블럭 내 문장들을 수행 후 전체 `try-catch`를 빠져나온다.
   3. 만일 일치하는 `catch`블럭이 없으면 예외는 처리되지 않는다. (JVM 예외처리기로 넘어감)
2. 발생하지 않은 경우
   1. `catch`블럭을 건너뛰고 전체 `try-catch`문을 빠져나와 수행을 계속한다.

---

예외가 발생하면, 발생한 예외에 해당하는 클래스의 인스턴스가 만들어진다.<br>
이 인스턴스는 발생한 예외에 대한 정보가 담겨있으며, `catch`문의 괄호`()`안 참조변수로 정보를 얻을 수 있다.

즉 `try`블럭 내 예외가 발생하면, 첫 `catch`블럭부터 차례로 내려가면서 괄호`()` 내 선언된<br>
⭐ 참조변수의 타입과 생성된 예외 인스턴스를 `instanceof` 연산자로 검사한다.

모든 예외 클래스는 `Exception`의 자손이므로, `catch` 블럭의 괄호`()`에 `Exception`타입의<br>
참조변수를 선언하면 어떤 종류의 예외가 발생해도 이 `catch`블럭에 의해 처리된다.

---

예외 인스턴스에 발생한 예외에 대한 정보에 접근하고자 할 때 다음 메서드를 주로 사용한다.

`printStackTrace()`<br>
예외 발생 당시의 호출 스택(`call stack`)에 있었던 메서드의 정보와 예외 메시지를 출력한다.

`getMessage()`<br>
발생한 예외 클래스의 인스턴스에 저장된 메시지를 얻을 수 있다.

---

`JDK 7`부터 여러 `catch`블럭을 `|`기호를 이용하여 하나의 `catch`블럭으로 합칠 수 있게 되었다.<br>
이를 멀티 `catch`블럭이라 하며 아래처럼 중복된 코드를 줄일 수 있다.

```java
// before
try {
    ...    
} catch (ExceptionA e) {
    e.printStackTrace();
} catch (ExceptionB e) {
    e.printStackTrace();    
}
```

```java
// after
try {
    ...
} catch (ExceptionA | ExceptionB e) {
    e.printStackTrace();
}
```

( `|` 기호로 연결할 수 있는 예외 클래스의 개수에는 제한이 없다 )<br>
( 멀티 `catch`블럭에서 사용하는 `|`는 논리 연산자가 아니다 )

⭐ 멀티 `catch`블럭에서 연결된 예외 클래스가 상속 관계에 있다면 컴파일 에러가 발생한다.

이러한 멀티 방식으로 예외를 처리할 경우, 실제로 어떤 예외가 발생한 것인지 알 수 없다.<br>
⭐ 따라서 참조변수 `e`로 예외 클래스들의 공통 분모인 조상 예외 클래스에 선언된 멤버만 사용할 수 있다.

```java
try {
    ...
} catch (ExceptionA | ExceptionB e) {
    e.methodA(); // error - ExceptionA의 메서드 methodA() 호출 불가

    if (e instanceof ExceptionA) {
        ExceptionA e1 = (Exception A) e;
        e1.methodA(); // ok - ExceptionA에 선언된 메서드 호출 가능
    } else { ... }
    
    e.printStackTrace();
}
```
