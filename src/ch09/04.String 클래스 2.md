# 04. String 클래스 2

`String`클래스 내에 정의된 주요 생성자와 메서드들을 살펴보도록 하겠다.

### 생성자

- `String(String s)` : 주어진 문자열을 갖는 String인스턴스 생성

```java
String s = new String("Hello");
```

- `String(char[] value)` : 주어진 문자열을 갖는 String인스턴스 생성

```java
char[] c = {'H', 'e', 'l', 'l', 'o'};
String s = new String(c);
```

- `String(StringBuffer buf)` : `StringBuffer`인스턴스가 가지고 있는 문자열과 동일 내용 `String`객체 생성

```java
StringBuffer sb = new StringBuffer("Hello");
String s = new String(sb);
```

---

### 멤버 메서드

- `char charAt(int index)` : 지정된 위치에 있는 문자열 반환

```java
String s = "Hello";
char c = s.charAt(2); // l
```

- `int compareTo(String str)` : 문자열(str)과 `사전 순서`로 비교, 같으면 0, 이전이면 음수, 이후면 양수

```java
int i1 = "aaa".compareTo("aaa"); // i1 = 0
int i2 = "aaa".compareTo("bbb"); // i2 = -1
int i3 = "bbb".compareTo("aaa"); // i3 = 1
```

- `String concat(String str)` : 문자열(str)을 `뒤에` 덧붙인 문자열 반환

```java
String s = "hello";
String s2 = s.concat(" world"); // s2 = "hello world"
```

- `boolean contains(CharSequence s)` : 지정된 문자열(s)이 `포함되었는지` 검사

```java
String s = "abcdefg";
boolean b = s.contains("bc"); // true
```

- `boolean endsWith(String suffix)` : 지정된 문자열(suffix)로 `끝나는지` 검사

```java
String s = "hello.txt";
boolean b = s.endsWith(".txt"); // true
```

- `boolean equals(Object obj)` : 문자열(obj)와 문자열 비교, `obj`가 `String`이 아니거나 다르면 `false`

```java
String s = "Hello";
boolean b = s.equals("Hello"); // true
boolean b = s.equals("hello"); // false
```

- `boolean equalsIgnoreCase(String str)` : 문자열과 `String`인스턴스의 문자열을 `대소문자 구분없이` 비교

```java
String s = "Hello";
String s2 = "hellO";

boolean b = s.equalsIgnoreCase(s2); // true 
```

- `String indent(int n)` : 문자열의 모든 행의 왼쪽에 주어진 숫자만큼 들여쓰기를 추가/삭제

```java
String s = "hello";
String s1 = s.indent(2); // "  hello"
String s2 = s1.indent(-1); // " hello", 공백 없으면 음수여도 변화없음
```

- `int indexOf(int ch)` : 주어진 `문자(int ch)`가 존재하는 지 확인하여 위치(`idx`)를 알려줌, 없으면 -1

```java
String s = "Hello";
int idx1 = s.indexOf('o'); // 4
int idx2 = s.indexOf('k'); // -1
int idx3 = s.indexOf('l'); // 2, 여러개면 먼저 나오는 index
```

- `int indexOf(int ch, int pos)` : 주어진 문자(`ch`)가 문자열에 존재하는지 지정된 위치(`pos`)부터 확인

```java
String s = "Hello";
int idx1 = s.indexOf('e', 0); // 1
int idx2 = s.indexOf('e', 1); // 1, 해당 위치(pos) 포함하여 확인한다
int idx3 = s.indexOf('e', 2); // -1
```

- `int indexOf(String str)` : 주어진 문자열을 찾아 위치(`index`) 반환, 없으면 -1

```java
String s = "ABCDEFG";
int idx = s.indexOf("DEF"); // 3
```

- `String intern()` : 문자열을 `상수풀(constant pool)`에 등록, 이미 같은 문자열이 상수풀에 존재하면 그 문자열의 주소값 반환

```java
String s =new String("abc");
String s2 = new String("abc");

boolean b = (s == s2); // false
boolean b2 = s.equals(s2); // true
boolean b3 = s.intern() == s2.intern(); // true
```

- `int lastIndexOf(int ch)` : 지정된 문자 또는 문자 코드를 문자열의 오른쪽 끝부터 찾아 위치 반환, 없으면 -1

```java
String s = "java.lang.Object";
int idx1 = s.lastIndexOf('.'); // 9
int idx2 = s.indexOf('.'); // 4
```

- `int lastIndexOf(String str)` : 지정된 문자열을 인스턴스의 문자열 끝에서부터 찾아 위치 반환, 없으면 -1

```java
String s = "java.lang.java";
int idx1 = s.lastIndexOf("java"); // 10
int idx2 = s.indexOf("java"); // 0
```

- `int length()` : 문자열 길이 반환

```java
String s = "hello";
int length = s.length(); // 5
```

- `String repeat(int count)` : 같은 내용이 여러 번 반복된 문자열 반환

```java
String s = "abc".repeat(3); // s = "abcabcabc"
```

- `String replace(char old, char nw)` : 문자열 중 문자(`old`)를 새로운 문자(`nw`)로 바꾼 문자열 반환

```java
String s = "Hello";
String s1 = s.replace('H', 'C'); // Cello
String s2 = s.replace('l', '?'); // He??o, 모든 문자(old)가 nw로 바뀐다 
```

- `String replace(CharSequence old, CharSequence nw)` : 문자열 중 문자열(`old`)를 문자열(`nw`)로 모두 바꾼 문자열 반환

```java
String s = "Hellollo";
String s1 = s.replace("ll", "LL"); // HeLLoLLo
```

- `String replaceAll(String regex, String replacement)` : 문자열 중 지정된 문자열(`regex`)과 일치하는 것을 새로운 문자열(`replacement`)로 모두 변경

```java
String ab = "AABBAABB";
String r = ab.replaceAll("BB", "bb"); // AAbbAAbb
```

( 위 두 메서드의 차이점이 뭘까? )

```java
String s = "a.b.c";

System.out.println(s.replace(".", "-")); // a-b-c
System.out.println(s.replaceAll(".", "-")); // -----
```

`replace`는 문자 그대로 비교하지만, `replaceAll()`은 `정규식(regex)`패턴을 사용해서 치환한다.

- `String replaceFirst(String regex, String replacement)` : 문자열 중 지정된 문자열과 일치하는 것 중, 첫 번째만 새로운 문자열로 변경

```java
String ab = "AABBAABB";
String r = av.replaceFirst("BB", "bb"); // AAbbAABB
```

- `String[] split(String regex)` : 문자열을 지정된 분리자(`regex`)로 나누어 문자열 배열에 담아 반환

```java
String animals = "dog,cat,bear";
String[] arr = animals.split(","); // {"dog", "cat", "bear"}
```

- `String[] split(String regex, int limit)` : 문자열을 분리자(`regex`)로 나누어 문자열 배열에 담아 반환, 단 문자열 전체를 지정된 수(`limit`)로 자른다.

```java
String animals = "dog,cat,bear";

String[] arr = animals.split(",", 2); // {"dog", "cat,bear"} 
```

- `boolean startsWith(String prefix)` : 주어진 문자열(`prefix`)로 시작하는지 검사

```java
String s = "java.lang.Object";
boolean b1 = s.startsWith("java"); // true
boolean b1 = s.startsWith("lang"); // false
```

- `String substring(int begin), String substring(int begin, int end)` : 시작 위치(`begin`)부터, 끝 위치(`end`) 범위에 포함된 문자열을 얻는다. 시작범위는 포함, 끝 범위는 미포함

```java
String s = "java.lang.Object";
String c = s.substring(10); // Object
String p = s.substring(5, 9); // lang
```

- `String toLowerCase()` : `String`인스턴스에 저장되어 있는 모든 문자열을 소문자로 변환하여 반환

```java
String s = "Hello";
String s1 = s.toLowerCase(); // hello
```

- `String toString()` : `String`인스턴스에 저장되어 있는 문자열을 반환

```java
String s = "Hello";
String s2 = s.toString(); // Hello
```

- `String toUpperCase()` : `String`인스턴스에 저장되어 있는 모든 문자열을 대문자로 변환 후 반환

```java
String s = "Hello";
String s2 = s.toUpperCase(); // HELLO
```

- `String trim()` : 문자열의 왼쪽 끝, 오른쪽 끝에 있는 공백을 제거한 결과 반환, 문자열 중간 공백은 안지워짐

```java
String s1 = " as d  ";
String s2 = s1.trim(); // as d
```

- `static String valueOf(boolean b), valueOf(char c) , valueOf(int i), valueOf(long l), valueOf(float f), valueOf(double d), valueOf(Object o)` : 지정된 값을 문자열로 변환하여 반환, 참조변수의 경우 `toString()`을 호출한 결과 반환

```java
String b = String.valueOf(true); // "true"
String c = String.valueOf('a'); // "a"
String i = String.valueOf(100); // "100"
String l = String.valueOf(100L); // 100"
String f = String.valueOf(10f); // "10.0"
String d = String.valueOf(10.0); // "10.0"

java.util.Date dd = new java.util.Date();
String date = String.valueOf(dd); // "Sat Mar 07 18:19:49 KST 2026"
```
