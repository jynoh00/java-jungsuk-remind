# 유용한 클래스 2
> `java.util`패키지에 있는 클래스 중 자주 사용되는 클래스들의 용도와 활용 방법에 대해 알아본다.

### 2. `java.util.Random`

```java
import java.util.Random;
```

기존에 난수를 얻기 위해서 `Math.random()`메서드를 활용했었다.<br>
이 외에도 `Random`클래스를 통해 난수를 얻을 수 있다.

사실 `Math.random()`메서드는 내부적으로 `Random`클래스의 인스턴스를 생성해서 사용하기에<br>
둘 중에 편한 것을 사용하면 된다.

```java
// 두 줄은 서로 동등한 코드이다.
double randNum = Math.random();
double randNum2 = new Random().nextDouble();
```

`1~6`사이의 난수를 얻고자 한다면 아래처럼 나타낼 수 있다.

```java
int num = (int) (Math.random() * 6) + 1;
int num2 = new Random().nextInt(6) + 1; // nextInt(6)은 0~6(포함 x)의 정수를 반환한다.
```

`Math.random()`과 `Random`클래스의 가장 큰 차이점은, 종자값(`seed`)을 설정할 수 있다는 것이다.

`seed`가 같은 `Random`인스턴스들은 항상 같은 난수를 같은 순서대로 반환한다.<br>
`seed`는 난수를 만드는 공식에서 사용되는 값으로 같은 공식에 같은 값을 넣으면 같은 결과를 얻는 것처럼

동일 시드를 넣으면 동일 난수를 얻게 된다.

---

```java
public Random() {
    this(System.currentTimeMillis()); // Random(long seed) 호출
}
```

`Random`클래스의 기본 생성자는 위 코드처럼 시스템의 현재 시간을 시드로 하기 때문에<br>
실행마다 다른 난수를 얻을 수 있다. ( `currentTimeMillis()`는 현재시간을 천분의 1초 단위로 변환한 값 반환 )

---

- `Random()` : 현재시간을 시드로 이용하는 랜덤 인스턴스 생성
- `Random(long seed)` : 매개변수 `seed`를 시드로 하는 랜덤 인스턴스 생성
- `boolean nextBoolean()` : `boolean`타입 난수 반환
- `void nextBytes(byte[] bytes)` : 매개변수 `bytes`배열에 `byte`타입 난수를 채운다
- `double nextDouble()` : `double`타입 난수 반환 (`0.0 <= x < 1.0`)
- `float nextFloat()` : `float`타입 난수 반환 (`0.0 <= x < 1.0`)
- `double nextGaussian()` : 평균은 `0.0`이고, 표준편차는 `1.0`인 가우시안 분포에 따른 `double`형 난수 반환
- `int nextInt()` : `int`타입의 난수 반환 (`int`의 범위)
- `int nextInt(int n)` : `int`타입의 난수 반환 (`0 <= x < n` 범위에 있는 정수)
- `long nextLong()` : `long`타입의 난수 반환 (`long`의 범위)
- `void setSeed(long seed)` : 시드를 주어진 값(`seed`)으로 변경한다

---

nextBytes()는 BigInteger(int signum, byte[] magnitude)와 함께 사용하면<br>
`int` 범위보다 넓은 범위의 난수를 얻을 수 있다.

```java
import java.util.Random;
import java.math.BigInteger;

public class RandomEx {
    public static void main(String[] args) {
        Random rd = new Random();
        
        byte[] randomBytes = new byte[16];
        rd.nextBytes(randomBytes);
        
        BigInteger bigRandom = new BigInteger(1, randomBytes);
        
        System.out.println("int보다 넓은 범위의 난수: " + bigRandom);
        // ex) int보다 넓은 범위의 난수: 187187071825802532157819869509580214961
    }
}
```

---

`code/RandomEx.java` 예시에서 `Math.random()`을 활용해 작성한 3개의 메서드들은<br>
각 다음 역할을 수행한다.

```java
public static int[] fillRand(int[] arr, int from, int to)
public static int[] fillRand(int[] arr, int[] data)
public static int getRand(int from, int to)
```

1. `fillRand(int[] arr, int from, int to)`는 매개변수 `arr`배열에<br>
`from`부터 `to`범위의 값들로 채운 후 `arr`배열을 반환한다.


2. `fillRand(int[] arr, int[] data)`는 매개변수 `arr`배열에<br>
`data`배열에 있는 값들로 랜덤하게 채워서 반환한다.

3. `getRand(int from, int to)`는 `from`부터 `to`범위의 정수값을 반환한다.<br>
이때 `from`과 `to`는 모두 범위에 포함된다.

---

불연속적인 값들을 임의로 얻어 와야 하는 경우가 있을 땐<br>
불연속 값들을 배열에 저장한 후, 해당 배열의 `index`를 랜덤으로 얻어 배열에 저장된 값을 읽도록 한다.

```java
Random rd = new Random();
int value = arr[rd.nextInt(arr.length)];
```
