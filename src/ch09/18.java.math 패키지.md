# 18. java.math 패키지

### 1. `java.math.BigInteger`

가장 큰 정수형 타입인 `long`으로 표현할 수 있는 값은 10진수로 19자리 정도이다.<br>
해당 값도 충분히 큰 값이지만, 과학적 계산에서는 더 큰 값을 다뤄야할 때가 있다. 이에 `BigInteger`를 사용한다.

`BigInteger`는 내부적으로 `int`배열을 사용해 값을 다룬다.<br>
따라서 `long`타입보다 큰 값을 다룰 수 있으나 성능은 `long`타입보다 떨어질 수 밖에 없다.

```java
final int signum; // 부호: 1(양수), 0, -1(음수) 중 하나
final int[] mag; // 값(magnitude)
```

`String`과 마찬가지로, `BigInteger` 또한 불변(`immutable`)값을 저장한다.

또한, 모든 정수형과 마찬가지로 `BigInteger`역시 값을 `2의 보수` 형태로 표현한다.<br>
부호를 따로 저장하고, 배열에는 값 자체만을 저장한다는 것이다.

따라서 부호만 다른 두 값의 `mag`는 동일하며, `signum`만 다른 값을 가진다.

---

```java
BigInteger val;
val = new BigInteger("12345678901234567890"); // 문자열로 생성
val = new BigInteger("FFFF", 16); // n진수(radix) 문자열로 생성
val = BigInteger.valueOf(1234567890L); // 숫자로 생성
```

`BigInteger`를 생성하는 방법으로, 문자열로 숫자를 표현하는 것이 일반적이다.
⭐ 정수형 리터럴로는 표현할 수 있는 값의 한계가 있기 때문이다.

---

`BigInteger`를 문자열, 또는 `byte[]`배열로 변환하는 메서드는 다음과 같다.

```Java
String toString() // 문자열로 변환
String toString(int radix) // 지정된 진법(radix)의 문자열로 반환
byte[] toByteArray() // byte 배열로 변환
```

앞서 살펴본 것 처럼 `Number` 클래스를 상속받는데, Number로부터 상속받은 기본형 변환 메서드들 또한 존재한다.

```java
byte byteValueExact()
int intValueExact()
long longValueExact()
```

주의할 점은 정수형 변환 메서드 중에서 이름 끝에 `Exact`가 붙은 것들은<br>
변환 결과가 변환한 타입의 범위에 속하지 않으면 `ArithmeticException`을 발생시킨다는 것이다.

---

다음은 `BigInteger`의 기본적인 연산을 수행하는 메서드들이다.

```java
BigInteger add(BigInteger val) // this + val
BigInteger subtract(BigInteger val) // this - val
BigInteger multiply(BigInteger val) // this * val
BigInteger divide(BigInteger val) // this / val
BigInteger remainder(BigInteger val) // this % val
```

앞서 언급한 것처럼 `BigInteger`는 불변이기에, 반환 타입이 `BigInteger`란 것은<br>
새로운 인스턴스가 반환된다는 뜻이다.

( `BigInteger`또한 `Integer`처럼 캐시 기능이 있다,<br>
`-16~16`범위 값이면 `valueOf()`가 캐시된 객체를 반환한다 )

아래는 비트 연산 메서드들이다.<br>
큰 숫자를 다루기에 성능을 향상시키기 위한 비트단위 연산 메서드들을 많이 가지고 있다.

```java
int bitCount() // 2진수 표현 시 1의 개수 (음수는 0의 개수)를 반환
int bitLength() // 2진수 표현 시 값을 표현하는데 필요한 bit수를 반환
boolean testBit(int n) // 우측에서 n+1번째 비트가 1이면 true, 0이면 false
BigInteger setBit(int n) // 우측에서 n+1번째 비트를 1로 변경
BigInteger clearBit(int n) // 우측에서 n+1번째 비트를 0으로 변경
BigInteger flipBit(int n) // 우측에서 n+1번째 비트를 전환 (1->0, 0->1)
```

( 이외에도 기본적인 `and, or, xor, not`과 같은 비트연산자를 구현한 메서드 또한 가지고 있다 )

---

정수가 짝수인지 확인할 때, 보통 정수를 `2`로 나눈 나머지가 `0`인지 확인한다.

```java
BigInteger bi = new BigInteger("4");
if (bi.remainder(new BigInteger("2")).equals(BigInteger.ZERO)) {
    // ...    
}
```

하지만 `BigInteger`에도 이러한 로직을 적용하면 위 코드처럼, 비효율적이며 코드가 복잡해진다.

따라서 짝수는 가장 오른쪽 비트가 `0`이기에, 이러한 로직을 차용하여 아래처럼 작성하는 것이 효율적이다.

```java
BigInteger bi = new bigInteger("4");

if (!bi.testBit(0)) { // 우측에서 0+1번째 비트가 0이면 false, 1이면 true
    // ...     
}
```

이처럼 `BigInteger`는 가능하면 산술연산 대신 비트연산으로 처리하도록 노력해야 한다.

( `BigInteger` 사용 예시 : `code/BigIntegerEx.java` )
