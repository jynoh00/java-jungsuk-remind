# 05. String 클래스 3

문자열의 좌우 공백을 제거할 때 사용하는 `trim()`메서드와, `strip()`메서드는<br>
비슷하지만 제거하는 공백의 종류가 다르다.

- `trim()`의 경우 : 

    유니코드 이전에 주로 사용하던 아스키(`ASCII`)에서 정의한 공백인 (` `)와 `\t`, `\n` 등만 제거


- `strip()`의 경우 :

    `유니코드`에서 추가적으로 정의된 공백 또한 제거한다.

또한 문자열의 왼쪽 공백만 제거할 수 있는 `stripLeading()`과 오른쪽 공백만 제거할 수 있는<br>
`stripTrailling()`도 `JDK 11`부터 추가되었다.

문자열이 여러 행일 경우, 모든 행의 공백을 제거하는 `stripIndent()`는 `JDK 15`부터 추가되었다.

⭐ ( 유니코드에서 공백으로 인식되는 문자는 `String`의 `isBlank()` 또는 `Character.isWhitespace(int)`로 확인 가능 )

```java
public class StringTest {
    public static void main(String[] args) {
        String str = "    \u2000Hello, world\u2000    ";
        System.out.println("[" + str + "]");
        System.out.println("[" + str.trim() + "]");
        System.out.println("[" + str.strip() + "]");
        System.out.println("[" + str.stripLeading() + "]");
        System.out.println("[" + str.stripTrailing() + "]");

        char ch = '\u2000';
        System.out.printf("U+%x is blank? %b%n", (int)ch, (ch+"").isBlank());
    }
}
```

```shell
[     Hello, world     ]
[ Hello, world ]
[Hello, world]
[Hello, world     ]
[     Hello, world]
U+2000 is blank? true
```

`join()`을 사용해 여러 문자열 사이에 구분자를 넣어 결합할 수 있다.<br>
구분자로 문자열을 자르는 `split()`과 반대의 작업이라 생각할 수 있다.

```java
String animals = "dog,cat,bear";
String[] arr = animals.split(",");
String str = String.join("-", arr); // static 메서드

System.out.println(str); // dog-cat-bear
```

`java.util.StringJoiner`를 사용해 문자열을 결합할 수도 있다.

```java
public StringJoiner(CharSequence delimiter,
                        CharSequence prefix,
                        CharSequence suffix) {
    ...
```

```java
import java.util.StringJoiner;

public class StringTest {
    public static void main(String[] args) {
        StringJoiner sj = new StringJoiner(",", "[", "]");
        String[] strArr = {"aaa", "bbb", "ccc"};

        for (String s : strArr) sj.add(s.toUpperCase());

        System.out.println(sj.toString()); // [AAA,BBB,CCC]
    }
}
```

앞서 `04.String 클래스 2.md`에서 살펴본 메서드 중에는<br>
매개변수의 타입이 `char`인 것도 있고 `int`인 것들도 있다. 문자를 다루는 메서드이기에<br>
매개변수의 타입이 `char`일 것 같은데 어째서 `int`인 것들이 있을까?

이유는 확장된 `유니코드를 다루기 위해`서이다.

유니코드는 본래 `2 byte`, 즉 `16 bit` 문자체계인데 이걸로 모자라 `20 bit`로 확장하게 되었다.

따라서 하나의 문자를 `char`타입으로 다루지 못하고 (자바에서 `char`타입은 `2 byte`)<br>
`int`타입으로 다룰 수 밖에 없게 된 것이다.

확장에 의해 새로 추가된 문자들을 `보충 문자(supplementary characters)`라 하는데<br>
`String`클래스의 메서드 중 보충문자를 지원하는 것이 있고 지원하지 않는 것도 있다.

이를 구별하는 방법은 매개변수가 `int ch`인 것들은 보충문자를 지원하는 것이며,<br>
`char ch`인 것들은 지원하지 않는 메서드들인 것이다.

서로 다른 문자 인코딩을 사용하는 시스템 간에 데이터를 주고 받기 위해<br>
적절한 문자 인코딩으로 변환이 필요하다. 그렇지 않으면 알아 볼 수 없는 내용의 문서가 나타나기 때문이다.

문자 인코딩 변환을 위해 `getBytes(String charsetName)`를 사용하여, 문자열의 인코딩을 변경할 수 있다.

```java
byte[] cp949_str = "가".getBytes("CP949"); // 인코딩을 CP949로 변환
String str = new String(cp949_str, "CP949"); // byte배열을 문자열로 변환
```

다음의 예로 이를 학인하여 보겠다.

```java
import java.io.UnsupportedEncodingException;
import java.util.StringJoiner;

public class StringTest {
    public static void main(String[] args) throws UnsupportedEncodingException {
        String str = "가";

        byte[] bArr = str.getBytes("UTF-8"); // UTF-8은 기본 인코딩으로 생략이 가능하다
        byte[] bArr2 = str.getBytes("CP949");

        System.out.println("UTF-8: " + joinByteArr(bArr));
        System.out.println("CP949: " + joinByteArr(bArr2));

        System.out.println("UTF-8: " + new String(bArr));
        System.out.println("CP949: " + new String(bArr2, "CP949"));
    }

    static String joinByteArr(byte[] bArr) {
        StringJoiner sj = new StringJoiner(":", "[", "]");

        for (byte b : bArr) {
            sj.add(String.format("%02X", b));
        }

        return sj.toString();
    }
}
```

```shell
UTF-8: [EA:B0:80]
CP949: [B0:A1]
UTF-8: 가
CP949: 가
```

`UTF-8`은 한글 한 글자를 `3 byte`로 표현하고, `CP949`에서는 `2 byte`로 표현한다.<br>
따라서 문자 `가`는 UTF-8로 `0xEAB080`이며, CP949로 `0xB0A1`인 것이다.

( 문자 인코딩은 CP949는 한글 윈도우의 기본 인코딩이며, MS949라고도 한다 )
