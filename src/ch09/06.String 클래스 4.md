# 06. String 클래스 4

```java
String str = String.format("%d 더하기 %d는 %d입니다.", 3, 5, 3+5);
System.out.println(str); // 3 더하기 5는 8입니다.
```

`format()`은 형식화된 문자열을 만들어내는 간단한 방법으로 사용법은 `printf()`와 완전 동일하다.

`formatted()`를 이용하여 아래처럼 표현도 가능하다.

```java
String str = "%d 더하기 %d는 %d입니다.";
System.out.println(str.formatted(3, 5, 3+5));
```

출력 부분에 `formatted()`대신 다음과 같이 `printf()`로 사용해도 동일하다.

```java
System.out.printf((str) + "%n", 3, 5, 3 + 5);
```

`기본형`과 `String` 서로간 변환은 다음과 같은 방법으로 가능하다.

먼저 숫자와 문자열간 변환이 이루어지는 경우가 잦은데, 먼저 숫자를 문자열로 변환하는 경우 아래와 같다.

```java
int i = 100;

String str1 = i + "";
String str2 = String.valueOf(i);
```

앞서 배운 방법으로 숫자에 빈 문자열 `""`을 더해주기만 하면 된다.

또는 `String.valueOf()`를 사용하는 방법이 있는데, 성능은 `valueOf()`가 더 좋지만<br>
빈 문자열을 더하는 방법이 간단하고 직관적이기 때문에 성능향상이 필요한 경우에만 `valueOf()`를 사용하도록 한다.

반대로 숫자로된 문자열을 숫자 기본형으로 변환하는 방법은 다음과 같다.

```java
int i = Integer.parseInt("100");
int i2 = Integer.valueOf("100");
```

원래 `valueOf()`의 반환 타입은 `int`가 아닌 `Integer`인데, 이후 배울 `오토박싱(auto-boxing)`에 의해<br>
`Integer`가 `int`로 자동 변환된다.

이전에는 `parseInt()`와 같은 메서드를 많이 사용하였으나, 메서드의 이름을 통일하기 위해 (`String.valueOf()`와 같이)<br>

`valueOf()`가 추가되었다. `valueOf(String s)`는 메서드 내부에서 그저 `parseInt(String s)`를<br>
호출할 뿐이므로, 두 메서드는 반환 타입만 다르지 같은 메서드이다.

```java
public static Integer valueOf(String s) throws NumberFormatException {
    return Integer.valueOf(parseInt(s, 10));
}
```

/* `main`에서 `Integer.valueOf()`를 호출하였음에도, 따로 예외처리없이 사용 가능한 이유는<br>
`valueOf()` 클래스 메서드가 던지는 예외인 `NumberFormatException`이 `RuntimeException`의<br>
자손 클래스이기에 `Unchecked Exception`이라 실행이 되는 것이다. */

다음 내용은 `기본형`과 `문자열`간 변환에 사용되는 주요 메서드들이다.

1. 기본형 -> 문자열
- `String String.valueOf(boolean b)`
- `String String.valueOf(char c)`
- `String String.valueOf(int i)`
- `String String.valueOf(long l)`
- `String String.valueOf(float f)`
- `String String.valueOf(double d)`

2. 문자열 -> 기본형
- `boolean`, `Boolean.parseBoolean(String s)`
- `byte`, `Byte.parseByte(String s)`
- `short`, `Short.parseShort(String s)`
- `int`, `Integer.parseInt(String s)`
- `long`, `Long.parseLong(String s)`
- `float`, `Float.parseFloat(String s)`
- `double`, `Double.parseDouble(String s)`

`Boolean`, `Byte`, `Integer` 등 기본형 타입의 이름의 첫 글자가 대문자인 것은<br>
`래퍼 클래스(wrapper class)`로, 기본형 값을 감싸고 있는 클래스라는 뜻에서 붙여진 이름이며 기본형을 클래스로 편한 것이다.

`ch09` 후반부에 자세히 다룬다.

---

문자열과 기본형간 변환에 있어, 중요한 것은 `문자열에 공백 또는 문자가 포함되어 있는 경우`이다.<br>
이때 변환 시 예외 (`NumberFormatException`)가 발생할 수 있기에<br>
문자열의 공백을 제거해주는 과정을 습관적으로 사용해야 한다.

```java
int val = Integer.parseInt(" 123 ".trim());
```

그러나 부호를 의미하는 `+`나 소수점을 의미하는 `.`, `float`형 값을 뜻하는 `f`와 같은<br>
자료형 접미사는 허용된다. ( 단 자료형에 알맞은 변환을 하는 경우에만 )

`"1.0f"`를 `int`형 변환 메서드인 `Integer.parseInt()`를 사용해서 변환하려하면 예외가 발생하지만<br>
`Float.parseFloat()`를 사용하면 아무런 문제가 없다.

### `컴팩트 문자열(compact string)`

`String`클래스는 문자열을 저장하기 위한 `char`배열을 가지고 있다 설명해 왔다.<br>
첫 부분에서 설명한 것처럼 사실 `char`배열이 아닌 `byte`배열을 사용한다.

이전에는 `char`배열이었으나 `JDK 9`부터 보다 효율적인 메모리 사용을 위해 `byte`배열로 변경되었으며

이를 `컴팩트 문자열(compact string)`이라 한다.

```java
public final class String implements java.io.Serializable, Comparable {
    private final byte[] value;
    ...
}
```

자바는 고정길이 인코딩인 UTF-16을 오랜 기간 사용해왔는데

모든 문자가 `2 byte`이기 때문에 문자를 다루기 쉽지만, 영문자와 숫자 등의 `1 byte` 문자들 또한<br>
`2 byte`를 차지하는 저장 공간의 비효율성이 따랐다.

따라서 문자열의 모든 문자가 `1 byte`로 표현 가능한 경우, (`Latin-1` 인코딩으로 이루어진 경우)<br>
`2 byte`가 아닌 `1 byte`로 저장되게 바뀌어 메모리도 절약하고 성능도 향상되었다.

`Latin-1` 인코딩이 아닌 경우엔 예전처럼 문자 하나를 `2 byte`로 저장한다.

이는 `JVM`이 알아서 결정하므로 크게 신경 쓸 필요는 없다. 컴팩트 문자열은 단지 내부적 변경일 뿐이기에<br>
이전과 동일하게 `String`클래스를 사용하면 된다.

( `JDK 18`부터 기본 인코딩이 `UTF-16`에서 `UTF-8`로 바뀌었지만, 저장은 위와 동일하다 )
