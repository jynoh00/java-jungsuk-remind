# 유용한 클래스 3
> `java.util`패키지에 있는 클래스 중 자주 사용되는 클래스들의 용도와 활용 방법에 대해 알아본다.

### 3. `java.util.regex`

```java
import java.util.regex.*;
```

정규식(`regular expression`)이란 텍스트 데이터 중 원하는 조건(`패턴, pattern`)과<br>
일치하는 문자열을 찾아내기 위해 사용하는 것으로, `미리 정의된 기호와 문자`를 이용하여 작성한 문자열을 말한다.

정규식을 이용할 경우, 많은 양의 텍스트 파일 중 `원하는 데이터를 손쉽게 뽑아`낼 수 있으며<br>
입력된 데이터가 `형식에 맞는지 체크`할 수 있디.

(Ex. HTML문서 크롤링 후 전화번호 추출, 입력한 비밀번호가 숫자와 영문자 조합인지 검사 etc. )

---

정규식을 자세히 알아보면, 책 한 권 분량이 될 정도로 광범위하기에 깊이 있는 학습보다<br>
자주 쓰이는 정규식의 작성 예를 보고 응용할 수 있도록 학습한다.

```java
import java.util.regex.*;
// import java.util.regex.Matcher; // Matcher클래스
// import java.util.regex.Pattern; // Pattern클래스

class RegularEx {
    public static void main(String[] args) {
        String[] data = {"bat", "baby", "bonus", "cA", "ca", "co", "c.",
                "c0", "car", "combat", "count", "date", "disc"};
        Pattern p = Pattern.compile("c[a-z]*");

        for (String datum : data) {
            Matcher m = p.matcher(datum);

            if (m.matches())
                System.out.println(datum + ",");
        }
    }
}
```

`data` 문자열 배열에 담긴 문자열 중, 지정한 정규식과 일치하는 문자열을 출력한다.

`Pattern`은 정규식을 정의하는데 사용되고 `Matcher`는 정규식(패턴)을 데이터와 비교하는 역할을 한다.

1. 정규식을 매개변수로 `Pattern`클래스의 `static`메서드인 `Pattern compile(String regex)`을 호출하여 `Pattern`인스턴스 객체를 얻는다.

```java
Pattern p = Pattern.compile("c[a-z]*");
```

2. 정규식으로 비교할 대상을 매개변수로 `Pattern`클래스의 `Matcher matcher(CharSequence input)`를 호출해서 `Matcher`인스턴스를 얻는다.

```java
Matcher m = p.matcher(data[i]);
```

3. `Matcher`인스턴스에 `boolean matches()`를 호출하여 정규식에 부합하는지 확인한다.

```java
if (m.matches()) {
```

( `CharSequence`는 인터페이스로, 이를 구현한 클래스는 `CharBuffer`, `String`, `StringBuffer`가 있다 )

---

아래 내용은 자주 쓰이는 정규식 패턴들에 대한 설명이다.

- `c[a-z]*` : `c`로 시작하는 영단어 (c, ca, co, car, combat, count,)
- `c[a-z]` : `c`로 시작하는 두자리 영단어 (ca,co,)
- `c[a-zA-Z]` : `c`로 시작하는 두 자리 영단어 (`a~z` 또는 `A~Z`, 즉 대소문자 구분 x) (cA, ca, co,)
- `c[a-zA-Z0-9]` : `c`로 시작하고 숫자와 영어로 조합된 두 글자 (cA, ca, co, c0,)
- `.*` : 모든 문자열 (bat, baby, ... , disc,)
- `c.` : `c`로 시작하는 두 자리 문자열 (cA, ca, c., c0, c#,)
- `c.*` : c로 시작하는 모든 문자열(기호 포함) (cA, ca, co, c., c0, c#, car, combat, count,)
- `c\.` : `c.`와 일치하는 문자열, `.`은 패턴작성에 사용되는 문자이므로 `escape`문자 `\`와 사용 (c.,)
- `c\d`, `c[0-9]` : `c`와 숫자로 구성된 두 자리 문자열 (c0,)
- `c.*t` : `c`로 시작하고 `t`로 끝나는 모든 문자열 (combat, count,)
- `[b|c].*`, `[bc].*`, `[b-c].*` : `b` 또는 `c`로 시작하는 문자열 (bat, baby, bonus, c, cA, ... , count,)
- `[^b|c].*`, `[^bc].*`, `[^b-c].*` : `b` 또는 `c`로 시작하지 않는 문자열 (date, disc,)
- `.*a.*` : `a`를 포함하는 모든 문자열, `*` - 0 또는 그 이상의 문자 (bat, baby, ca, car, combat, date,)
- `.*a.+` : `a`를 포함하는 모든 문자열, `+` - 1 또는 그 이상의 문자, `+`는 `*`과 달리 반드시 하나 이상의 문자가 있어야 하므로 `a`로 끝나는 단어는 포함되지 않는다. (bat, baby, car, combat, date,)
- `[b|c].{2}` : `b` 또는 `c`로 시작하는 세 자리 문자열 (`b` 또는 `c` 다음에 두 자리이므로 모두 세 자리) (bat, car,)

정규식 패턴을 활용한 연습 예제는 `code/RegularEx.java`에서 살펴보도록 한다.

String pattern = "(0\\d{1,2})-(\\d{3,4})-(\\d{4})";

패턴에 대한 자세한 설명은 코드의 주석으로 대체하며, 이때 괄호를 통해 그룹화로 묶여있는 걸 확인할 수 있다.

```java
    while (m.find())
        System.out.println(++i + ": " + m.group(0) + " -> " + m.group(1) +
                ", " + m.group(2) + ", " + m.group(3));
```

`m.find()`로 패턴과 매치하는 부분을 찾아내어, `group(int i)`을 통해 패턴에서 괄호로 그룹화 해놓은<br>
각 그룹들을 호출할 수 있다.

`code/RegularEx3.java`에서는 `StringBuffer`를 활용하여 문자열의 치환 기능이 구현되어 있다.

```java
while (m.find()) {
    System.out.println(++i + "번째 매칭: " + m.start() + "~" + m.end());
    m.appendReplacement(sb, "drunken");
}
```

이전 예제와 마찬가지로 `m.find()`를 통해 매치하는 부분을 반복하여 찾아나가며<br>
`start()`, `end()`를 통해 일치부의 시작과 끝 `index`정보를 얻을 수 있다. (`end()` 끝 인덱스 + 1)

`appendReplacement(sb, "drunken")`메서드를 통해, `"broken"`과 일치하는 내용을<br>
`"drunken"`으로 치환하여 미리 생성해놓은 `StringBuffer` 객체에 저장한다.

`while()`반복이 종료된 후에는 `appendTail(sb)`메서드를 통해 뒷 부분을 마저 `sb`에 붙여준다.

```java
m.appendTail(sb);
```

실행 순서마다 나누어 `StringBuffer`객체인 `sb`에 저장된 값을 알아보면

1. 문자열 `source`에서 `"broken"`을 `m.find()`로 찾아 처음으로<br>
`m.appendReplacement(sb, "drunken")`메서드가 호출되면<br>
시작부터 `"broken"`을 찾은 위치까지의 내용에 `"drunken"`을 더해서 저장한다.<br>
(sb: "A drunken")


2. `m.find()`는 첫 발견 위치의 끝에서부터 다시 검색을 시작하여 두 번째 `"broken"`을 찾게 된다.<br>
다시 `m.appendReplacement(sb, "drunken")`가 호출된다.<br>
(sb : "A drunken hand works, but not a drunken")


3. `m.appendTail(sb)`이 호출되며 마지막으로 치환된 이후의 부분을 `sb`에 덧붙인다.<br>
(sb : "A drunken hand works, but not a drunken heart.")
