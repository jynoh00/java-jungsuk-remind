# 10. Math 클래스
> `Math` 클래스는 기본적인 수학 계산에 유용한 메서드로 구성되어 있다.

임의의 수를 얻을 수 있는 `random()`과 반올림에 사용되는 `round()`처럼<br>
앞서 배운 메서드를 포함한 다양한 멤버가 존재한다.

`Math`클래스는 생성자의 접근 제어자가 `private`이기 때문에 다른 클래스에서 `Math`인스턴스를 생성할 수 없다.<br>
⭐ 그 이유는 클래스 내에 인스턴스 변수가 하나도 없어 인스턴스를 생성할 필요가 없기 때문이다.

`Math`클래스의 메서드는 모두 `static`이며, 아래와 같이 3개의 `상수`를 제공한다.

```java
public static final double E = 2.7182818284590452354;
public static final double PI = 3.14159265358979323846;
public static final double TAU = 2.0 * PI;
```

### 올림, 버림, 반올림

소수점 `n`번째 자리에서 반올림한 값을 얻기 위해선 `round()`를 사용한다.

`round()`는 항상 소수점 첫째자리에서 반올림을 하여 정수값(`long`)을 결과로 돌려준다.

따라서 `원하는 자리 n에서 반올림된 값`을 얻기 위해 간단히 10의 `n`제곱을 곱한 후<br>
다시 곱한 수로 나눠주기만 하면 된다.

ex) `90.7552`에서 소수점 두자리(`n = 2`)까지의 값을 얻고 싶다.

```java
90.7552 * 100 = 9075.52

Math.round(9075.52) -> 9076

9076 / 100.0 = 90.76
```

만약 반올림이 필요하지않다면, 그저 `10^n`로 곱한 후 (정수로 변환), `10^n.0`으로 나누기만 하면<br>
소수점 `n`번째 자리까지의 값을 얻을 수 있다.

```java
double pi = 3.141592;

double result = (int)(pi * 1000) /  1000.0; // 3.141, n = 3 자리까지 나타냄 (반올림 x)
double result2 = Math.round(pi * 1000) / 1000.0; // 3.142, n = 3 자리로 반올림
```

메서드 이름에 `Exact`가 포함된 메서드들이 `JDK 8`부터 추가되었다.<br>
이들은 `정수형간의 연산에서` 발생할 수 있는 오버플로우(`overflow`)를 감지하기 위한 것이다.

```java
int addExact(int x, int y) // x + y
int subtractExact(int x, int y) // x - y
int multiplyExact(int x, int y) // x * y
int incrementExact(int a) // a++
int decrementExact(int a) // a--
int negateExact(int a) // -a
int toIntExact(long value) // (int) value
```

기본 연산자를 활용하면 단지 결과를 반환할 뿐, 오버플로우의 발생여부에 대해 알려주지 않는다.<br>
그러나 위 메서드들은 오버플로우가 발생하면, 예외(`ArithmeticException`)를 발생시킨다.

( 부호를 바꾸는 연산은 `~a+1`이며 `~a`의 결과가 `int`의 최대값이면, 오버플로우가 발생할 수 있다 )<br>
( `JDK 18`부터 `divideExact()`, `ceilDivExact()`, `floorDivExact()`가 더 추가 되었다 )

---

`StrictMath`클래스는 `OS`마다 `Math`클래스에서의 계산 과정에서 다른 값이 나올 수 있어<br>
( `Math`클래스는 최대한의 성능을 위해 `JVM`이 설치된 OS의 메서드`native method`를 호출하여 사용함 )<br>
( 동일 자바로 작성된 코드라 할지라도, 연산 처리방법이 컴퓨터마다 다를 수 있어 다른 결과가 나올 수 있음 )

차이를 없애고자 성능을 다소 포기하고,<br>
어떤 `OS`에서 실행되어도 항상 같은 결과를 얻도록 `Math`클래스를 새로 작성한 클래스이다.

다음은 `Math`클래스의 주요 메서드들이다.

1. 절대값 반환 

```java
static double abs(double a)
static float abs(float f)
static int abs(int f)
static long abs(long f)
```

2. 올림 반환

```java
static double ceil(double a)
```

3. 버림 반환

```java
static double floor(double a)
```

4. 두 값 비교 큰 쪽 반환

```java
static double max(double a, double b)
static float max(float a, float b)
static int max(int a, int b)
static long max(long a, long b)
```

5. 두 값 비교 작은 쪽 반환

```java
static double min(double a, double b)
static float min(float a, float b)
static int min(int a, int b)
static long min(long a, long b)
```

6. `0.0` ~ `1.0` 범위의 임의의 `double`값 반환 (`1.0`은 미포함)

```java
static double random()
```

7. 주어진 `double`값과 가장 가까운 정수값을 `double`로 반환, 단 두 정수의 가운데 값이면 짝수 반환

```java
static double ceil(double a)
```

8. 소수점 첫째자리에서 반올림한 정수값(`long`)을 반환한다.

```java
static long round(double a)
static long round(float f)
```
