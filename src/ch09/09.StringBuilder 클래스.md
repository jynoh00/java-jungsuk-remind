# 09. StringBuilder 클래스
> `StringBuffer`와 완전히 똑같은 기능을 가지는 성능 향상 클래스

⭐ `StringBuffer`는 멀티쓰레드에 안전(`thread-safe`)하도록 동기화되어 있다.

쓰레드와 동기화와 관련된 내용은 추후 `ch13`에서 자세히 다루며,<br>
동기화가 `StringBuffer`의 성능을 떨어뜨린다는 것만 이해하면 된다.

멀티 쓰레드로 작성된 프로그램의 경우 `StringBuffer`의 이러한 동기화가 필요하겠지만<br>
⭐ 아닌 경우 `StringBuffer`의 동기화는 불필요하게 성능만 떨어뜨린다는 것이다.

( 지금까지의 모든 프로그램은 전부 싱글 쓰레드로 작성된 것이며, 멀티 쓰레드 프로그램은 `ch13`에서 다룬다 )

---

따라서 `StringBuffer`에서 쓰레드의 동기화만 뺀 `StringBuilder` 클래스가 새로 추가되었다.

`StringBuffer`와 완전히 똑같은 기능으로 작성되어 있기에 소스 코드에서 `StringBuffer`를,<br>
`StringBuilder`로 바꾸기만 하면 동일하게 작동한다.

```java
StringBuffer sb;
sb = new StringBuffer();
sb.append("abc");
```

```java
StringBuilder sb;
sb = new StringBuilder();
sb.append("abc");
```

`StringBuffer`도 충분히 성능이 좋기 때문에, `성능 향상이 반드시 필요한 경우`를 제외하곤<br>
기존 작성한 코드에서 `StringBuffer`를 `StringBuilder`로 굳이 바꿀 필요는 없다.
