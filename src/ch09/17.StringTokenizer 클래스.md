# 17. StringTokenizer 클래스
> 긴 문자열로 지정된 구분자(`delimiter`)를 기준으로 토큰(`token`)이라는 여러 개의 문자열로 잘라낼 때 사용

```java
import java.util.StringTokenizer;
```

`StringTokenizer` 이외에도 `String`의 `split(String regex)`이나<br>
`Scanner`의 `useDelimiter(String pattern)`를 사용할 수도 있지만

```java
String[] result = "100,200,300,400".split(",");
Scanner sc = new Scanner("100,200,300,400").useDelimiter(",");
```

위 두 가지 방법은 `regex`을 사용해야 하기에, 정규식 표현에 익숙하지 않다면<br>
`StringTokenizer`를 사용하는 것이 간단하면서도 명확한 결과를 얻을 수 있다.

그러나 `StringTokenizer`는 구분자로 단 하나의 `문자`만 사용할 수 있기에<br>
보다 복잡한 형태의 구분자로 문자열을 나누어야 할 때는 어쩔 수 없이 정규식을 사용하는 메서드를 사용하도록 한다.

---

```java
StringTokenizer(String str, String delim)
StringTokenizer(String str, String delim, boolean returnDelims)
```

`StringTokenizer`클래스의 생성자는 위와 같다.<br>
문자열(`str`)을 지정된 구분자(`delim`)로 나누는 `StringTokenizer`를 생성하는데<br>
`returnDelims`의 값을 `true`로 하면 `구분자도 토큰으로 간주`되게 된다.

아래는 주요 메서드들이다.

```java
int countTokens() // 전체 토큰의 수 반환
boolean hasMoreTokens() // 토큰이 남아있는 지 확인
String nextToken() // 다음 토큰 반환
```

---

```java
import java.util.StringTokenizer;

public class StringTokenizerEx {
    public static void main(String[] args) {
        String source = "100,200,300,400";
        StringTokenizer st = new StringTokenizer(source, ",");

        while (st.hasMoreTokens()) {
            String token = st.nextToken();
            System.out.println(token);
        }
    }
}
```

`,`를 구분자로 하는 `StringTokenizer`객체를 생성하여, 문자열(`source`)을 나누어<br>
`token` 단위로 출력하는 간단한 예제이다.

---

```java
String expression = "x=100*(200+300)/2";
StringTokenizer st = new StringTokenizer(expression, "+-*/=()", true);

while (st.hasMoreTokens()) {
    System.out.println(st.nextToken());    
}
```

생성자에 `boolean` 매개변수 `true`를 추가하여, 구분자 또한 토큰으로 간주되도록 한 예제이다.

```shell
x
=
100
*
(
200
+
300
)
/
2
```

`StringTokenizer`는 한 문자의 구분자만 사용할 수 있다 하였는데<br>
`delim`의 데이터 타입이 `String`인 이유를 위 코드를 통해 알 수 있다.

즉, `"+-*/=()"` 전체가 하나의 구분자가 아니라, 각각의 문자가 모두 구분자로 활용된다는 것이다.

---

`"1,김천재,100,100,100|2,박수재,95,80,90|3,이자바,80,90,90"`

위 `String` 문자열을 `StringTokenizer`를 통해 구분해본다면

```java
String source = "1,김천재,100,100,100|2,박수재,95,80,90|3,이자바,80,90,90";
StringTokenizer st = new StringTokenizer(source, "|");
```

먼저 `|`를 구분자로 `"1,김천재,100,100,100"`, `"2,박수재,95,80,90"`, `"3,이자바,80,90,90"`<br>
3개의 토큰으로 나눈다.

```java
while(st.hasMoreTokens()){
    String token = st.nextToken();
    StringTokenizer st2 = new StringTokenizer(token, ",");
    
    while(st2.hasMoreTokens()) {
        // ...    
    }
}
```

이후 `st`를 `while`로 토큰 순회하며, 각 토큰을 반복문 내부에 새로운 `StringTokenizer`객체 `st2`를 통해<br>
구분자 `,`로 분리하여, 세부 토큰을 얻는 식으로 활용할 수 있다.

---

```java
String data = "100,,,200,300";

String[] result = data.split(",");
for (String s : result) System.out.print(s + "*");

System.out.println();

StringTokenizer st = new StringTokenizer(data, ",");
while (st.hasMoreTokens()) {
    System.out.print(st.nextToken() + "*");
}
```

동일 `data` 문자열을 `String`의 `split()`과 `StringTokenizer`를 활용하여 결과를 얻으면

```shell
100***200*300*
100*200*300*
```

위 결과를 얻을 수 있다.

코드를 통해 살펴보면, `split` 메서드를 활용한 결과는 `result` 문자열 배열이 총 5개의 값을 가진다.<br>
{`"100"`, `""`, `""`, `"200"`, `"300"`}

즉 `split()`은 빈 문자열도 토큰으로 인식하는 반면, `StringTokenizer`는 빈 문자열을 토큰으로 인식하지 않아<br>
{`"100"`, `"200"`, `"300"`}

3개의 토큰만 존재하는 것을 확인할 수 있다.

---

이외에도 성능의 차이가 있는데, `split()`은 데이터를 토큰으로 잘라낸 결과를 배열에 담아 반환하기에<br> 
데이터를 토큰으로 바로바로 잘라서 반환하는 `StringTokenizer`보다 성능이 떨어질 수 밖에 없다.

그러나 데이터 양이 많은 경우가 아니라면 큰 문제가 되지는 않는다.
