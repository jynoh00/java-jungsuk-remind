# 03. String 클래스 1
> 자바에서는, 문자열을 위한 클래스를 제공하며 이는 String 클래스이다.

`String`클래스에는 무낮열을 저장하기 위해 문자형 배열 참조변수(`char[]`) `value`를<br>
인스턴스 변수로 선언해놓고 있다. ( `JDK 9`부터 메모리 절약을 위해 `byte[]`로 바뀌었다, 이해를 위해 char[]로 )

```java
public final class String implements java.io.Serializable, Comparable {
    private final char[] value; // 문자열을 저장하기 위한 "불변" 배열
    ...
}
```

한번 생성된 `String`인스턴스의 문자열은 읽기만 가능하며 변경할 수 없다.

`+`연산자를 이용해 문자열을 결합하고자 할 때, 문자열이 바뀌는 것이 아닌 새로운 문자열이 담긴<br>
`String`인스턴스가 생성되는 것이다.

```java
String a = "a";
String b = "b";

a = a + b;
```

`String` 참조변수인 `a`가 가리키는 객체가 멤버 변수만 바꾸는게 아닌 새로운(`"ab"`) 객체를 가리키는 것이다.

이와 같은 `+` 기호를 사용한 문자열 결합은 매 연산 시 마다 새로운 문자열을 가진<br>
⭐ `String`인스턴스를 생성하는 과정을 거치며 메모리 공간을 차지하게 되므로 가능하면 결합 횟수를 최소화해야한다.

따라서 문자열간의 결합이나 추출 등 문자열을 다루는 작업이 많이 필요한 경우,<br>
`String`클래스 대신 `StringBuffer`클래스를 사용하는 것이 좋다.

`StringBuffer`인스턴스에 저장된 문자열은 변경이 가능하기에 하나의 `StringBuffer`인스턴스만으로<br>
문자열을 다루는 것이 가능하다.

---

문자열을 만들 때는 두 가지 방법이 있다.

1. 문자열 리터럴을 지정하는 방법
2. `String`클래스의 생성자로 만드는 방법

```java
String s1 = "abc";
String s2 = "abc";

String s3 = new String("abc");
String s4 = new String("abc");
```

생성자로 생성한 경우 `new` 연산자에 의해 메모리 할당이 이루어지기에, 항상 새로운 인스턴스가 생성된다.<br>
반면 문자열 리터럴은 이미 존재하는 것을 재사용하는 것이다.

⭐문자열은 `불변(immutable)`이기에 여러 곳에서 공유해도 문제가 없는 것이다.

( 문자열 리터럴은 클래스가 메모리에 로드될 때 자동적으로 미리 생성된다 )

위 `s1` ~ `s4`까지의 문자열을 비교하여보겠다.

```java
System.out.println(s1 == s2); // true
System.out.println(s1.equals(s2)); // ture

System.out.println(s3 == s4); // false
System.out.println(s3.equals(s4)); // true
```

- `s1 == s2`의 결과는 두 참조변수가 같은 문자열 리터럴 주소를 가리키기에, `true`가 반환된다.
- `s1.equals(s2)`는 두 문자열의 값이 동일하게 `true`가 반환된다.
- `S3 == S4`는 두 참조변수가 서로 다른 `String`인스턴스의 주소를 가리키기에 `false`가 반환된다.
- `s3.equals(s4)`는 `String`클래스가 `Object`클래스의 `equals()`를 오버라이딩하여<br>
주소가 달라도 문자열의 내용만 비교하도록 작성되었기에 다른 객체라 할지라도 `true`가 반환된다.

---

자바 소스 파일에 포함된 모든 `문자열 리터럴`은 `컴파일 시 클래스 파일에 저장`되는데<br>
이때 `같은 내용의 문자열 리터럴은 한번만` 저장된다.

문자열 리터럴도 `String`인스턴스이고, 한번 생성하면 내용을 변경할 수 없으니 하나의 인스턴스를 공유해도 되기 때문이다.

```java
public class StringTest {
    public static void main(String[] args) {
        String s1 = "abc";
        String s2 = new String("abc");

        System.out.println(s1 == s2); // false

        System.out.println(s1.getClass()); // class java.lang.String
        System.out.println(s2.getClass()); // class java.lang.String
    }
}
```

(문자열 리터럴도 `String`인스턴스 )

클래스 파일에는 소스 파일에 포함된 모든 리터럴의 목록이 있다. 해당 클래스 파일이 `클래스 로더`에 의해<br>
메모리에 올라갈 때, 이 리터럴의 목록에 있는 리터럴들이 `JVM`내에 있는 `상수 저장소(constant pool)`에 저장된다.

이때 이곳에 문자열 리터럴이 자동적으로 생성되어 저장되는 것이다.

자바에서는 길이가 `0`인 배열이 `C언어`에서와 다르게 존재할 수 있다.

`char`배열도 길이가 `0`인 배열을 생성할 수 있고, 이 배열을 내부적으로 가지고 있는 문자열이 바로 `빈 문자열`이다.

```java
String s = "";
```

참조변수 `s`가 참조하고 있는 `String`인스턴스는 내부에 `new char[0]`과 같이 길이가 `0`인 배열을 저장하고 있다.

```java
char[] chArr = new char[0]; // 길이 0 char 배열
int[] arr = {}; // 길이 0 int 배열
```

길이가 0이기에 어떤 문자도 저장할 수 없는 배열이라 무의미하게 느껴질 수 있지만, 이러한 표현이 가능하다.<br>
( `char`형 변수에는 반드시 하나의 문자를 지정해야 한다 `char c = '';`는 불가능 )

일반적으로 변수를 선언할 때, 각 타입의 기본값으로 초기화하지만

- `String`은 참조형 타입의 기본값이 `null`보다 `빈 문자열`로
- `char`형은 기본값인 `\u0000` 대신 공백(` `)으로 초기화하는 것이 보통이다.
