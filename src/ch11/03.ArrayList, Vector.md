# ArrayList, Vector 클래스
> `ArrayList`는 `Vector`를 개선한 것으로, 차이점은 `동기화`이다.

### ArrayList

`Vector` 클래스와 다르게 `ArrayList`는 동기화 되어 있지 않다.

```java
public class ArrayList extends AbstractList 
        implements List, RandomAccess, Cloneable, java.io.Serializable {
    ...
    transient Object[] elementData; // 오브젝트 배열
    ...
} 
```

( `transient`는 직렬화(`serialization`)와 관련된 제어자로, 자세한 사항은 15장에서 알아본다 )

- `ArrayList`는 오브젝트 배열을 이용해 데이터를 순차적으로 저장한다.
- 배열에 저장할 공간이 부족하면, 보다 큰 새로운 배열을 생성하여 기존 배열에 저장된 내용을 복사 후 저장한다.
- 성능이 크게 중요한 경우가 아니라면, 배열대신 `ArrayList`를 사용하도록 한다. ( 코드 안정성 ) 

```java
ArrayList() // 크기 10 어레이리스트 생성
ArrayList(Collection c) // 컬렉션이 저장된 어레이리스트 생성

Object get(int index)

boolean isEmpty()
int size()
void trimToSize() // 용량을 크기에 맞게 줄인다 (빈 공간 제거)

Object remove(int index)
boolean remove(Object o)

```

`exOne()` : ( `code/ArrayListEx.java` 참조 )

```java
for (int i = list2.size() - 1; i >= 0; i--) {
    if (list.contains(list2.get(i))) {
        list2.remove(i);
    }
}
```

위 코드에서 `index` `i`의 값을 `0`이 아닌 뒷 부분부터 감소하는 형태로 설정되어 있는데

`i`를 증가시키면 `list2.remove(i);`를 진행한다면 한 요소가 삭제될 때마다 빈 공간을 채우기 위해<br>
나머지 요소들이 자리 이동을 하게 되어, 올바른 동작이 이루어지지 않는다.

따라서 제어변수인 `i`를 감소시키며 삭제해야 자리이동이 발생해도 영향을 받지 않고, 작업이 가능하다.

`exThree()` : ( `code/ArrayListEx.java` 참조 )

`exThree()`는 벡터의 용량(`capacity`)과 크기(`size`)를 알아보는 예제이다.

각 과정에서 배열은 크기(`capacity`)를 변경할 수 없기에, 공간이 충분하지 않다면 새로운 배열을 생성해서 반환하고<br>
기존 배열은 추후 가비지컬렉터에 의해 메모리에서 제거된다.

```java
v.trimToSize();
```

-> 기존 `capacity`가 5이기에, 3으로 줄이는 과정에서 새로운 배열 생성

```java
v.ensureCapacity(6);
```

-> 기존 `capacity`가 3이기에, 최소 용량을 6으로 늘리기 위해 새로운 배열 생성

```java
v.setSize(7);
```

-> 기존 `capacity`가 6이며, `size`는 3이었다. 따라서 `size`를 7로 하기 위해,<br>
`capacity`또한 늘어나야하며, 따라서 새로운 인스턴스가 생성된다.

-> `Vector`는 `capacity`가 부족할 경우, 자동적으로 기존 크기보다 2배인 크기로 `capacity`가 설정된다.

```java
v.clear();
```

-> `Vector`객체의 모든 요소를 제거, `size`는 0이되며, `capacity`는 12가 유지된다.

일련의 과정에서 용량을 변경해야 할 때, 새로운 배열을 생성한 후 기존 배열을 복사하는 과정이 수행될 수 있기에<br>
효율성 측면에서 초기 용량을 적절히 지정하여 인스턴스를 생성하도록 한다.

( `code/MyVector.java` 참조 )

위 예제는 `List`를 구현한 `MyVector` 클래스로, 벡터의 동작원리에 대해 알아보는 코드이다.

```java
private void setCapacity(int capacity) {
    if (this.capacity == capacity) return;

    Object[] tmp = new Object[capacity];
    System.arraycopy(data, 0, tmp, 0, size);

    data = tmp;
    this.capacity = capacity;
}
```

책에선 `setCapacity()`를 위처럼 구현하였으나,<br>
`capacity`가 줄어드는 경우, `size`가 바뀔 수 있기에 추가 수정이 필요하다.

```java
private void setCapacity(int capacity) {
    if (this.capacity == capacity) return;
    
    if (capacity < size)
        size = capacity;

    Object[] tmp = new Object[capacity];
    System.arraycopy(data, 0, tmp, 0, size);

    data = tmp;
    this.capacity = capacity;
}
```
