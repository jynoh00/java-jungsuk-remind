# 02. List, Set, Map 인터페이스

### `List`

리스트 인터페이스는 중복을 허용하며, 저장 순서가 유지되는 컬렉션을 구현하는데 사용된다.

주요 클래스들의 상속 계층 구조는 아래와 같다.

- `List`
  - `Vector`
    - `Stack`
  - `ArrayList`
  - `LinkedList`

`Collection`인터페이스로부터 상속받은 것을 제외한, 메서드는 아래와 같다.

```java
// 오버로딩
void add(int index, Object element) // 지정 위치에 객체 추가
boolean addAll(int index, Collection c) // 지정 위치에 컬렉션에 포함된 객체들 추가

Object get(int index)
int indexOf(Object o)
int lastIndexOf(Object o) // 지정된 객체의 위치를 역방향으로 찾아 반환

ListIterator listIterator()
ListIterator listIterator(int index)

Object remove(int index) // 지정 위치 객체 삭제 후, 삭제된 객체 반환
Object set(int index, Object element) // 지정 위치에 객체 저장
void sort(Comparator c) // 비교자를 통해 리스트 정렬
List subList(int fromIndex, int toIndex) // 지정 범위에 있는 객체를 리스트로 반환
```

---

### `Set`

셋 인터페이스는 중복을 허용하지 않고, 저장 순서가 유지되지 않는 컬렉션 클래스를 구현하는데 사용된다.

주요 클래스들의 상속 계층 구조는 아래와 같다.

- `Set`
  - `SortedSet`
      - `TreeSet`
  - `HashSet`

---

### `Map`

맵 인터페이스는 키-값 쌍을 묶어 저장하는 컬렉션 클래스를 구현하는데 사용된다.<br>
키는 중복될 수 없으며 값은 중복을 허용한다. 동일 키에 값을 저장하면 기존 값은 없어지며, 마지막 값이 저장된다.

상속 계층 구조는 아래와 같다.

- `Map`
  - `HashMap`
      - `LinkedHashMap`
  - `Hashtable`
  - `SortedMap`
    - `TreeMap`

다음은 맵 인터페이스의 주요 메서드 목록이다.

```java
void clear()
    
boolean containsKey(Object key)
boolean containsValue(Object value)
    
Set entrySet() // 맵에 저장되어 있는 키-값 쌍을 Map.Entry타입의 객체로 저장한 Set으로 반환

boolean equals(Object o)
Object get(Object key)
int hashCode()
boolean isEmpty()
    
Set keySet() // 맵에 저장되어 있는 모든 key 객체를 반환
Collection values() // 맵에 저장된 모든 value객체 반환

Object put(Obkect key, Object value) // 키-값 쌍 매핑 후 저장
void putAll(Map t) // 지정 맵의 모든 키-값 쌍을 저장

Object remove(Object key)
int size()
static Entry entry(Object k, Object v) // 지정 키, 값을 Entry객체로 묶어 반환
```

`Map`인터페이스에서는 벨류는 중복을 허용하기에 `Collection`타입으로 반환하며<br>
키값은 `Set`타입으로 반환한다.

### Map.Entry interface

`Map.Entry`는 `Map` 인터페이스의 내부 인터페이스로<br>
내부 클래스처럼 인터페이스 역시 인터페이스 내부에 내부 인터페이스를 정의할 수 있다.

`Map`에 저장되어 있는 `key`-`value`쌍을 다루기 위해 내부적으로 정의해 놓은 인터페이스이며

보다 객체지향적 설계를 유도하기 위한 것으로 `Map`인터페이스를 구현하는 클래스에서는<br>
`Map.Entry`인터페이스도 함께 구현해야한다.

```java
public interface Map {
    ...
    public static interface Entry {
        Object getKey();
        Object getValue();
        Object setValue(Object value);
        boolean equals(Object o);
        int hashCode();
        ...
    }
}
```

### factory method

`of()`, `copyOf()`는 `List`, `Set`, `Map`을 생성해 반환하는 팩토리 메서드로<br>
배열의 생성과 초기화를 동시에 하는 것과 같은 코드를 작성할 수 있게 해준다.

- `of()`의 경우 가변인자와 오버로딩을 이용하여 괄호안에 여러 객체를 넣을 수 있다.

```java
List list = List.of("aaa", "bbb", "ccc");
// 3개의 요소가 저장된 List를 반환한다. (읽기 전용)

/*
        List 객체가 아니다. List 타입으로 참조 가능한 객체를 반환하는 것
 */
```

`Set`의 경우 위 코드에서 `List`를 `Set`으로 바꾸면 되며, `Map`은 `of()`가 아닌 `ofEntries()`이다.

```java
static Map ofEntries(Entry... entries)
```

또한 `copyOf()`는 매개변수로 컬렉션을 받아 복사해서 반환한다.<br>
반환된 컬렉션은 `얕은 복사`로 복사된 것이며 `읽기만 가능`하고, 변경할 수 없다.

```java
List list = List.of("aaa", "bb", "ccc");
List copy = List.copyOf(list);
copy.add("ddd"); // error
```

( `list.add("ddd");`도 에러가 발생한다.<br>
이유는 `List.of()`를 통해 만들어진 객체가 불변 객체이기에 읽기만 가능하기 때문이다. )

```java
static List copyOf(Collection coll)
static Set copyOf(Collection coll)
static Map copyOf(Map map)
```

### SequencedCollection interface

`SequencedCollection`인터페이스는 `JDK 21`부터 추가된 인터페이스로<br>
`Collection`의 자손이자 `List`의 조상이다.

- `Collection`
  - `SequencedCollection`
    - `List`
  - `Set`

정의되어 있는 디폴트 메서드는 다음과 같다.

```java
default void addFirst(Object e) { ... }
default void addLast(Object e) { ... }

default Object getFirst() { ... }
default Object getLast() { ... }

default Object removeFirst() { ... }
default Object removeLast() { ... }

default List reversed() { ... } // 컬렉션 역순으로 List에 담아 반환
```

기존 `List` 인터페이스를 구현한 클래스의 메서드 중 공통으로 사용할 수 있는 것들을 뽑아<br>
인터페이스로 따로 정의한 것이다.
