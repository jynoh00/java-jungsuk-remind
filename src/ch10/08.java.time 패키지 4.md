# 08. java.time 패키지 4

### `isAfter()`, `isBefore()`, `isEqual()`

`LocalDate`, `LocalTime` 모두 `compareTo()`가 적절히 오버라이딩 되어 있기에<br>
`compareTo()`로 비교할 수 있다.

```java
int result = date1.compareTo(date2); // 같으면 0, date1이 이전이면 -1, 이후면 +1
```

그럼에도 보다 편리하게 비교하기 위해 메서드들이 추가로 제공된다.

```java
boolean isAfter(ChronoLocalDate other)
boolean isBefore(ChronoLocalDate other)
boolean isEqual(ChronoLocalDate other) // LocalDate에만
```

`equals()`가 있음에도 `isEqual()`을 제공하는 이유는 연표가 다른 두 날짜를 비교하기 위함이다.<br>
모든 필드가 일치해야하는 `equals()`와 달리 `isEqual()`은 오직 날짜만 비교한다.

대부분의 경우 (연표 일치) `isEqual()`과 `equals()`는 같은 결과를 반환한다.

```java
LocalDate kDate = LocalDate.of(1999, 12, 31);
JapaneseDate jDate = LocalDate.of(1999, 12, 31);

System.out.println(kDate.equals(jDate)); // false : YEAR_OF_ERA가 다르다
System.out.println(kDate.isEqual(jDate)); // true
```
