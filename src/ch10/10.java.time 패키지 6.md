# 08. java.time 패키지 6

### TemporalAdjusters

```java
LocalDate today = LocalDate.now();
LocalDate nextMonday = 
        today.with(TemporalAdjusters.next(DayOfWeek.MONDAY));
```

`TemporalAdjusters`클래스는 자주 쓰일만한 날짜 계산들을 대신 해주는 메서드를 정의해놓았으며<br>
이를 통해 지난 주 토요일이 며칠인지, 이번 달 3번째 금요일이 며칠인지와 같은 날짜 계산을 쉽게 할 수 있다.


- `firstDayOfNextYear()` : 다음 해의 첫 날


- `firstDayOfNextMonth()` : 다음 달의 첫 날


- `firstDayOfYear()` : 올 해의 첫 날


- `firstDayOfMonth()` : 이번 달의 첫 날


- `lastDayOfYear()` : 올 해의 마지막 날


- `lastDayOfMonth()` : 이번 달의 마지막 날


- `firstInMonth(DayOfWeek dayOfWeek)` : 이번 달의 첫 번째 ?요일


- `lastInMonth(DayOfWeek dayOfWeek)` : 이번 달의 마지막 ?요일


- `previous(DayOfWeek dayOfWeek)` : 지난 ?요일(당일 미포함)


- `previousOrSame(DayOfWeek dayOfWeek)` : 지난 ?요일(당일 포함)


- `next(DayOfWeek dayOfWeek)` : 다음 ?요일(당일 미포함)


- `nextOrSame(DayOfWeek dayOfWeek)` : 다음 ?요일(당일 포함)


- `dayOfWeekInMonth(int ordinal, DayOfWeek dayOfWeek)` : 이번 달의 n번째 ?요일

---

보통 위 `TemporalAdjusters`클래스에 정의된 메서드로 충분하지만<br>
자주 사용되는 날짜 계산을 해주는 메서드를 직접 구현할 수도 있다.

`LocalDate`의 `with()`는 다음과 같이 정의되어 있으며

```java
LocalDate with(TemporalAdjuster adjuster)
```

`TemporalAdjuster`인터페이스를 구현한 클래스의 객체를 매개변수로 제공한다.<br>
( `TemporalAdjuster`는 인터페이스, `TemporalAdjusters`는 클래스 )

`TemporalAdjuster`인터페이스는 다음처럼 추상 메서드 하나만 정의되어 있으며, 이 메서드만 구현하면 된다.

```java
@FunctionalInterface
public interface TemporalAdjuster {
    Temporal adjustInto(Temporal temporal);
}
```

실제로 구현해야하는 메서드는 `adjustInto()`지만,<br>
이번에 `TemporalAdjuster`와 같이 사용해야 하는 메서드는 `with()`이다.

`with()`와 `adjustInto()` 중에서 어느 쪽을 사용해도 괜찮지만<br>
`adjustInto()`는 내부적으로만 사용할 의도로 작성된 것이기에, `with()`를 사용하게 구현한다.

대부분의 시간, 날짜 관련 클래스들은 `Temporal`인터페이스를 구현하였기에<br>
`adjustInto()`메서드의 매개변수로 사용이 가능하다.

예로, 특정 날짜로부터 2일 후의 날짜를 계산하는 `DayAfterTomorrow`는 다음처럼 구현 가능하다.

```java
class DayAfterTomorrow implements TemporalAdjuster {
    @Override
    public Temporal adjustInto(Temporal temporal) {
        return temporal.plus(2, ChronoUnit.DAYS);
    }
}
```

```java
LocalDate today = LocalDate.now();
LocalDate date = today.with(new DayAfterTomorrow());
```
