# 04. ChoiceFormat, MessageFormat

### `1. ChoiceFormat`
> 특정 범위에 속하는 값을 문자열로 변환해주는 형식화 클래스이다.

연속적 또는 불연속적인 범위의 값들을 처리하는 데 있어 `if`, `switch`문은 적절하지 못한 경우가 많기에<br>
이럴 때 `ChoiceFormat`을 사용하여 복잡하게 처리된 코드를 간단하고 직관적으로 만들 수 있다.

```java
import java.text.ChoiceFormat;
```

```java
final double[] limits = {60, 70, 80, 90};
final String[] grades = {"D", "C", "B", "A"};

int[] scores = {100, 95, 88, 70, 52, 60, 70};

ChoiceFormat form = new ChoiceFormat(limits, grades);

for (int score : scores)
    System.out.println(score + ": " + form.format(score));
```

위 예제를 통해 살펴보면, 하나의 배열(`limits`)은 범위의 경계값을 저장하는데 사용하였고<br> 
다른 하나의 배열(`grades`)은 범위에 포함된 값을 치환할 문자열을 저장하는데 사용되었다.

이때 경계값은 `double`형으로 반드시 오름차순 정렬되어 있어야 하며,<br>
치환될 문자열의 개수는 경계값에 의해 정의된 범위의 개수와 일치해야 한다.

⭐ ( 일치하지 않다면 `IllegalArgumentException`이 발생한다 )

위 예제에서는 `limits` 배열에 의해,<br>
`x < 70`, `70 <= x < 80`, `80 <= x < 90`, `90 <= x`의 범위가 정의되었다.

---

```java
String pattern = "60#D|70#C|80<B|90#A";
int[] scores = {91, 90, 80, 88, 70, 52, 60};

ChoiceFormat cf = new ChoiceFormat(pattern);

for (int score : scores)
    System.out.println(score + cf.format(score));
```

위 예제는 패턴을 사용하여 `ChoiceFormat`을 사용한 것이다.

- `#`는 경계값을 범위에 포함시키며 (`<=`)
- `<`는 경계값을 포함시키지 않는다 (`<`)

`limit#value`, `limit<value` 형태로 패턴을 작성한다.

---

### `2. MessageFormat`
> 데이터를 정해진 양식에 맞게 출력할 수 있도록 도와주는 클래스이다.

데이터가 들어갈 자리를 마련해 놓은 양식을 미리 작성하고,<br>
프로그램을 이용해 다수의 데이터를 같은 양식으로 출력할 때 사용할 수 있다.

```java
String msg = "Name: {0} \nTel: {1} \nAge: {2} \nBirthday: {3}";

Object[] arguments = {
        "이자바", "02-123-1234", "27", "07-09"
};

String result = MessageFormat.format(msg, arguments);
System.out.println(result);
```

`{숫자}`로 표시된 부분이 데이터가 출력될 자리가 된다.<br>
이 자리는 순차적일 필요가 없으며, 여러 번 반복해서 사용할 수도 있다. (인덱스는 `0`부터 시작한다)

양식에 들어갈 데이터는 객체(`Object` 인스턴스) 배열인 `arguments`에 저장된다.

객체 배열이기에 `String`외에도 다른 객체들이 지정될 수 있으며, 이 경우 보다 세부적인 옵션들이 사용될 수 있다.

이런 옵션이 사용되는 빈도가 낮기에 알아만 두도록 한다.

---

```java
String tableName = "CUST_INFO";
String msg = "INSERT INTO " + tableName + " VALUES (''{0}'', ''{1}'', ''{2}'', ''{3}'');";

Object[][] arguments = {
        {"이자바", "02-123-1234", "27", "07-09"},
        {"김프로", "032-333-1234", "33", "10-07"},
};

for (int i = 0; i < arguments.length; i++) {
    String result = MessageFormat.format(msg, arguments[i]);
    System.out.println(result);
}
```

위 예제처럼 다수의 데이터를 데이터베이스에 저장하기 위한 `Insert`문으로 변환하는 경우 등에 사용할 수 있다.

```sql
INSERT INTO CUST_INFO VALUES ('이자바', '02-123-1234', '27', '07-09');
INSERT INTO CUST_INFO VALUES ('김프로', '032-333-1234', '33', '10-07');
```

---

```java
String[] data = {
        "INSERT INTO CUST_INFO VALUES ('이자바', '02-123-1234', '27', '07-09');",
        "INSERT INTO CUST_INFO VALUES ('김프로', '032-333-1234', '33', '10-07');",
};

String pattern = "INSERT INTO CUST_INFO VALUES ({0}, {1}, {2}, {3});";
MessageFormat mf = new MessageFormat(pattern);

for (int i = 0; i < data.length; i++) {
    Object[] objs = mf.parse(data[i]);
    for (int j = 0; j < objs.length; j++) {
        System.out.print(objs[j] + ", ");    
    }
    System.out.println();
}
```

반대로 `parse(String source)`를 사용하여, 출력된 데이터로부터 필요한 데이터만을 뽑아내는 것 역시 가능하다.
