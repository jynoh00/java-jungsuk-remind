# 08. java.time 패키지 7

### Period, Duration

`Period`는 날짜의 차이를, `Duration`은 시간의 차이를 계산하기 위한 것이다.

```java
import java.time.Period;

LocalDate date1 = LocalDate.of(2024, 1, 1);
LocalDate date2 = LocalDate.of(2025, 12, 31);

Period pe = Period.between(date1, date2);
```

`Period` 인스턴스는 두 날짜간 차이를 나타내는 `between()`메서드를 통해 얻을 수 있으며<br>
`date1`이 `date2`보다 날짜 상으로 이전이면 양수, 이후면 음수로 `Period`에 저장된다. (동일하면 `0`)

```java
import java.time.Duration;

LocalTime time1 = LocalTime.of(00, 00, 00);
LocalTime time2 = LocalTime.of(12, 34, 56);

Duration du = Duration.between(time1, time2);
```

`Duration` 역시 동일한 방법으로 `LocalTime`간 차이를 구한다. 결과값이 나타내는 것 또한 동일하다.

---

`Period`와 `Duration`에서 특정 필드 값을 얻기 위해 `get()`을 사용한다.

```java
long year = pe.get(ChronoUnit.YEARS); // int getYears()
long month = pe.get(ChronoUnit.MONTHS); // int getMonths()
long day = pe.get(ChronoUnit.DAYS); // int getDays()

long sec = du.get(ChronoUnit.SECONDS); // long getSeconds()
long nano = du.get(ChronoUnit.NANOS); // long getNano()
```

주석으로 작성해놓은 메서드 또한 사용 가능하다.

그런데 `Period`와 다르게 `Duration`에는 `getHours()`, `getMinutes()` 같은 메서드가 없다.

`getUnits()` 메서드로 이를 확인할 수 있는데<br>
해당 메서드는 `get()`에 사용할 수  있는 `ChronoUnit`의 종류를 확인하고 `get()`메서드를 활용한다.

```java
System.out.println(pe.getUnits()); // [Years, Months, Days]
System.out.println(du.getUnits()); // [Seconds, Nanos]
```

따라서 `Duration`에서 시간, 분 필드 값을 얻고자 할 경우

```java
LocalTime tmpTime = LocalTime.of(0, 0).plusSeconds(du.getSeconds());

int hour = tmpTime.getHour();
int min = tmpTime.getMinute();
int sec = tmpTime.getSecond();
int nano = du.getNano();
```

위처럼 `LocalTime`에 `00:00:00`시간에 `Duration` 초 값을 더하여 값을 얻는다.

---

`until()` 메서드는 `between()`과 유사한 기능을 하는 메서드인데<br>
차이점은 `between()`은 스태틱 메서드이지만, `until()`은 인스턴스 메서드이다.

```java
Period pe = today.until(myBirthDay);
long dDay = today.until(myBirthDay, ChronoUnit.DAYS);
```

`Period`는 년월일을 분리저장하기에, `D-day`를 구하고자 할 경우<br>
두 개의 매개변수를 받는 `until()` 인스턴스 메서드를 사용하는 것이 좋다.

시간에도 `until()`을 사용할 수 있지만, `Duration`을 반환하는 `until()`은 없다.

```java
long sec = LocalTime.now().until(endTIme, ChronoUnit.SECONDS);
```

---

`Period`에는 `of()`, `ofYears()`, `ofMonths()`, `ofWeeks()`, `ofDays()`<br>
`Duration`에는 `of()`, `ofDays()`, `ofHours()`, `ofMinutes()`, `ofSeconds()` 등의 메서드가 있다.

`of`메서드의 사용법은 `LocalDate`와 `LocalTime`에서 배운 것과 동일하다.

```java
Period pe = Period.of(1, 12, 31); // 1년 12개월 31일
Duration du = Duration.of(60, ChronoUnit.SECONDS); // 60초
```

`with()` 메서드를 통해 특정 필드의 값을 변경할 수도 있다.

```java
pe = pe.withYears(2); // 1년 -> 2년으로. withMonths(), withDays()
du = du.withSeconds(120); // 60초 -> 120초로. withNanos()
```

---

`plus()`, `minus()`외에 곱셈 나눗셈 메서드 또한 존재한다.

```java
pe = pe.minusYears(1).multipliedBy(2); // 1년 뺀 후 2배 곱
du = du.plusHours(1).divideBy(60); // 1시간 더한 후 60으로 나눈다.
```

( `Period`에는 나눗셈을 위한 메서드가 따로 없다 )

음수를 확인하는 메서드와, `0`인지 확인하는 메서드는 아래처럼 사용한다.

```java
boolean sameDate = Period.between(date1, date2).isZero();
boolean isBefore = Duration.between(time1, time2).isNegative();
```

부호를 반대로 변경하는 `negated()`, 부호를 없애는 `abs()`또한 메서드로 존재한다.

```java
du = du.abs();
```

위 코드는 아래와 동일하다.

```java
if (du.isNegative())
    du = du.negated();
```

---

`Period`에 `normalized()`메서드를 사용하면 월(month)의 값이 12를 넘지 않게<br>
즉 1년 13개월을 2년 1개월로 바꿔준다. 일(day)의 길이는 일정하지 않기에 그대로 둔다.

```java
pe = Period.of(1, 13, 32).normalized(); // 1년 13개월 32일 -> 2년 1개월 32일
```

---

`Period`와 `Duration`을 다른 단위의 값으로 변환하고자 할 때 `to`로 시작하는 메서드들을 활용한다.

`get()`은 특정 필드의 값을 그대로 가져오지만, 아래의 메서드들은 특정 단위로 변환한 결과를 반환한다.


```java
// Period
long toTotalMonths() // 년월일을 월단위로 변환해서 반환 (일 단위는 무시)

// Duration
long toDays() // 일단위로 변환해서 반환
long toHours() // 시간단위로 변환 반환
long toMinutes() // 분단위로 변환 반환
long toMillis() // 밀리초 단위로 변환 반환
long toNanos() // 나노초 단위로 변환 반환
```

( 반환타입은 모두 `long`으로 지정 단위 이하의 값들은 버려진다는 의미이다 )

---

`LocalDate`의 `toEpochDay()` 메서드는 에포크 데이부터 날짜를 세어 반환하는데<br>
이 메서드를 활용하면 `Period`를 사용하지 않고도 두 날짜간의 일수를 편리하게 계산 가능하다.

단, 두 날짜 모두 에포크 데이 이후의 것이어야 한다.

```java
LocalDate date1 = LocalDate.of(2024, 8, 22);
LocalDate date2 = LocalDate.of(2024, 8, 23);

long period = date2.toEpochDay() - date1.toEpochEDay(); // 1
```

`LocalTime`의 경우에도 `int toSecondOfDay()`, `long toNanoOfDay()` 메서드가 있기에<br>
`Duration`을 사용하지 않고도 뺄셈을 통해 시간차를 계산할 수 있다.
