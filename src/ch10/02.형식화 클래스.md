# 02. 형식화 클래스
> `java.text`패키지에 포함되어 있는 클래스로, 형식화에 사용될 패턴을 정의하여 데이터를 정의된 패턴에 맞춰 형식화한다.

⭐ 데이터를 정의된 패턴으로 형식화할 수 있을 뿐만 아니라, 역으로 형식화된 데이터에서 기존 데이터를 얻어낼 수도 있다.

즉 형식화된 데이터의 패턴만 정의해주면 복잡한 문자열에서 `substring()`을 사용하지 않고도<br>
쉽게 원하는 값을 얻어낼 수 있다는 것이다.

---

### 1. `DecimalFormat`

숫자를 형식화 하는데 사용되는 것이 `DecimalFormat`이다.<br>
숫자데이터를 정수, 부동소수점, 금액 등의 다양한 형식으로 표현이 가능하며,<br>
반대로 텍스트 데이터를 숫자로 변환 가능하다.

( 형식화 클래스에서는 패턴을 정의하는 것이 전부라 할 수 있다 )

- `0` : 10진수(값이 없을 때는 0)
> `0` -> 1234568<br>
> `0.0` -> 1234567.9<br>
> `0000000000.0000` -> 0001234567.8900

- `#` : 10진수
> `#` -> 1234568<br>
> `#.#` -> 1234567.9<br>
> `#######.##` -> 1234567.89

- `.` : 소수점
> `#.#` -> 1234567.9

- `-` : 음수 부호
> `#.#-` -> 1234567.9-<br>
> `-#.#` -> -1234567.9

- `,` : 단위 구분자
> `#,###,##` -> 1,234,567,89<br>
> `#.####.##` -> 123,4567,89

- `E` : 지수 기호

- `;` : 패턴구분자
- `%` : 퍼센트
- `\u2030` : 퍼밀(퍼센트 x 10)
- `'` : escape 문자

---

`DateFormat`을 사용하고자 한다면, 원하는 출력형식의 패턴을 작성하여 `DecimalFormat`인스턴스를 생성한 후

출력하고자 하는 문자열로 `format`메서드를 호출하면 원하는 패턴으로 변환된 문자열을 얻을 수 있다.

```java
double number = 1234567.89;
DecimalFormat df = new DecimalFormat("#.#E0");
String result = df.format(number);
```

`code/DateFormatEx.java`에서 주요 패턴들의 테스트 예제를 살펴볼 수 있다.

---

```java
DecimalFormat df = new DecimalFormat("#,###.##");
DecimalFormat df2 = new DecimalFormat("#.###E0");

try {
    Number num = df.parse("1,234,567.89");
    System.out.print("1,234,567.89 -> ");
    
    double d = num.doubleValue();
    System.out.print(d + " -> ");
    
    System.out.print(df2.format(num));
} catch (Exception e) {
    //
}
```

`parse`메서드를 이용해 기호와 문자가 포함된 문자열을 숫자로 변환하였다.

( `Integer.parseInt`메서드는 콤마가 포함된 문자열을 숫자로 변환하지 못한다 )

`parse(String source)`는 `DecimalFormat`의 조상인 `NumberFormat`에 정의된 메서드로

```java
public Number parse(String source) throws ParseException
```

선언부는 위와 같다. 이때 `Number`클래스는 `Integer`, `Double`과 같은<br>
숫자를 저장하는 래퍼 클래스의 조상이며, `doubleValue()`메서드는 `Number`에 저장된 값을

`double`형의 값으로 변환하여 반환한다.<br>
이외에도 `intValue()`, `floatValue()`등의 메서드가 `Number`클래스에 정의되어 있다.
