# 02. 형식화 클래스
> `java.text`패키지에 포함되어 있는 클래스로, 형식화에 사용될 패턴을 정의하여 데이터를 정의된 패턴에 맞춰 형식화한다.

⭐ 데이터를 정의된 패턴으로 형식화할 수 있을 뿐만 아니라, 역으로 형식화된 데이터에서 기존 데이터를 얻어낼 수도 있다.

즉 형식화된 데이터의 패턴만 정의해주면 복잡한 문자열에서 `substring()`을 사용하지 않고도<br>
쉽게 원하는 값을 얻어낼 수 있다는 것이다.

---

### 1. `DecimalFormat`

숫자를 형식화 하는데 사용되는 것이 `DecimalFormat`이다.<br>
숫자데이터를 정수, 부동소수점, 금액 등의 다양한 형식으로 표현이 가능하며,<br>
반대로 텍스트 데이터를 숫자로 변환 가능하다.

( 형식화 클래스에서는 패턴을 정의하는 것이 전부라 할 수 있다 )

- `0` : 10진수(값이 없을 때는 0)
> `0` -> 1234568<br>
> `0.0` -> 1234567.9<br>
> `0000000000.0000` -> 0001234567.8900

- `#` : 10진수
> `#` -> 1234568<br>
> `#.#` -> 1234567.9<br>
> `#######.##` -> 1234567.89

- `.` : 소수점
> `#.#` -> 1234567.9

- `-` : 음수 부호
> `#.#-` -> 1234567.9-<br>
> `-#.#` -> -1234567.9

- `,` : 단위 구분자
> `#,###,##` -> 1,234,567,89<br>
> `#.####.##` -> 123,4567,89

- `E` : 지수 기호
> `#EO` -> 1234568<br>
> `#.#` -> 1234567.9<br>
> `#######.##` -> 1234567.89
