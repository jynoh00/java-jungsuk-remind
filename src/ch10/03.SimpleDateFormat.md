# 03. SimpleDateFormat
> `Date`와 `Calendar`만을 이용하여 날짜 데이터를 출력하는 것은 불편하기에, `SimpleDateFormat`을 사용한다.

기존 `Date`, `Calendar`를 사용해 날짜를 계산하는 방법을 배웠으며,<br>
출력하고자 할 경우 `SimpleDateFormat`을 사용한다.

- `DateFormat`은 추상 클래스로, `SimpleDateFormat`의 조상이다 )


- `DateFormat`은 추상 클래스이기에, 인스턴스를 생성하고자 할 때,<br>
`getDateInstance()`와 같은 팩토리 메서드를 이용한다


- `getDateInstance()`에 의해 반환되는 것은 `DateFormat`을 상속받아 완전하게 구현된,<br>
`SimpleDateFormat`인스턴스이다.

---

```java
import java.text.SimpleDateFormat;
```

```java
Date today = new Date();
SimpleDateFormat df = new SimpleDateFormat("yyyy-MM-dd");

String result = df.format(today);
```

원하는 출력형식의 패턴을 작성하여 `SimpleDateFormat` 인스턴스를 생성한 후, 출력하고자 하는<br>
`Date` 인스턴스를 가지고 `format(Date d)` 메서드를 호출하면 지정된 출력형식으로 변환된 문자열이 반환된다.

---

- `G` : 연대 (BC, AD)
- `y` : 년도
- `M` : 월
- `w` : 년의 몇 번째 주 (1~53)
- `W` : 월의 몇 번째 주 (1~5)
- `D` : 년의 몇 번째 일 (1~366)
- `d` : 월의 몇 번째 일 (1~31)
- `F` : 월의 몇 번째 요일 (1~5)
- `E` : 요일
- `a` : 오전/오후 (AM, PM)
- `H` : 시간 (0~23)
- `k` : 시간 (1~24)
- `K` : 시간 (0~11)
- `h` : 시간 (1~12)
- `m` : 분 (0~59)
- `s` : 초 (0~59)
- `S` : 천분의 일초 (0~999)
- `z` : Time zone (General time zone)
- `Z` : Time zone (RFC 822 time zone)
- `'` : escape 문자

위 문자들은, `SimpleDateFormat`의 패턴에 사용되는 주요 기호들이다.

`code/DateFormatEx.java` 예제 코드를 통해 사용법에 대해 알아보도록 한다.

---

`Calendar`인스턴스를 출력하고자 할 때는, `Date` 인스턴스만 `format`메서드에 사용될 수 있기에<br>
`Calendar`인스턴스를 `Date`인스턴스로 변환하여 출력한다.

```java
Calendar cal = Calendar.getInstance();
Date day = cal.getTime();

SimpleDateFormat sdf = new SImpleDateFormat("yyyy-MM-dd HH:mm:ss.SSS");

System.out.println(sdf.format(day));
```

( 반대로 `Date`인스턴스를 `Calendar`인스턴스로 변환하고자 할 경우, `setTime()`메서드를 사용한다 )

---

```java
// main
DateFormat df = new SimpleDateFormat("yyyy년 MM월 dd일");
DateFormat df2 = new SimpleDateFormat("yyyy/MM/dd");

try {
    Date d = df.parse("2024년 8월 23일");
    System.out.println(df2.format(d));
} catch (Exception e) {
    // ...
}
```

`parse(String source)`를 사용하여 날짜 데이터의 출력형식을 변환하는 과정이다.

`SimpleDateFormat`의 `parse(String source)`는 문자열 `source`를 날짜 `Date`인스턴스로 변환해준다.

`substring`메서드를 사용하지 않고도, 사용자의 날짜 입력 문자열에서 원하는 데이터를 뽑아낼 수 있다.
