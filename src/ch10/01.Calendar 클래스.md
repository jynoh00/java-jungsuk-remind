# 01. Calendar 클래스
> Date와 함께 날짜와 시간을 다루기 위한 클래스이다. 

`Date`, `Calendar`는 모두 날짜와 시간을 다룰 목적으로 제공되어온 클래스이다.

`Date`클래스의 문제점을 개선하여 나온 것이 `Calendar`클래스이며,<br>
이 또한 몇가지 단점들이 발견되어 `Java 8`부터 `java.time`패키지가 기존의 단점을 개선하고 추가되었다.

그럼에도 `Calendar`와 `Date`는 지금도 많이 사용되고 있기에 배워야한다.

( 이때 `Date`클래스는 `java.util.Date`이다, `java.sql`패키지의 `Date`클래스와 혼동 주의 )

---

```java
Calendar cal = new Calendar(); // error!
Calendar cal = Calendar.getInstance();
```

`Calendar`는 추상클래스이다. 따라서 직접 `new`연산자를 통해 객체를 생성할 수 없고<br>
메서드를 통해서 완전히 구현된 클래스의 인스턴스를 얻어야 한다.

`getInstance()`메서드는 `Calendar`를 구현한 클래스의 인스턴스를 반환한다.

`Calendar`를 상속받아 구현한 클래스로는 `GregorianCalendar`, `BuddhistCalendar`가 있다.<br>
`getInstance()`메서드 내에서 시스템의 국가와 지역설정을 확인한 후

태국인 경우 `BuddhistCalendar`, 그 외에는 `GregorianCalendar`의 인스턴스를 반환한다.

```java
class MyApp {
    public static void main(String[] args) {
        Calendar cal = new GregorianCalendar();
        // ...
    }
}
```

위와 같이 특정 인스턴스를 생성하도록 프로그램이 작성되어 있다면<br>
다른 종류의 역법을 사용하는 국가에서 실행한다던가, 새로운 역법이 추가된다던가 하는 경우

즉, 다른 종류의 인스턴스를 필요로 하는 경우에 `MyApp`을 변경해야 한다.

그러나 아래처럼 상황에 따라 다른 종류의 `Calendar`를 반환하는 `팩토리 메서드`로부터<br>
인스턴스를 얻게 되면 `MyApp`을 변경하지 않아도 된다.

```java
class MyApp {
    public static void main(String[] args) {
        Calendar cal = new Calendar.getInstance();
        // ...
    }
}
```

`getInstance()`메서드의 내용만 수정하면되기 때문이다.<br>
`getInstance()`메서드가 `static`메서드인 이유는, 메서드 내 코드에서 인스턴스 변수를 사용하거나<br>
인스턴스 메서드를 호출하지 않기 때문이며,

또 다른 이유는 `getInstance()`가 `static`이 아니라면 위와 같이 객체를 생성한 다음에 호출해야 하는데<br>
`Calendar`는 추상클래스이기 때문에 객체를 생성할 수 없기 때문이다.

---

`Calendar`가 추가되며 기존 `Date`는 대부분 메서드가 `deprecated` 되었기에 잘 사용하지 않는다.<br>
그럼에도 여전히 `Date`를 필요로 하는 메서드들이 존재하기에,

`Calendar`를 `Date`로 또는 그 반대로 변환하는 경우가 필요하다.

`Calendar -> Date`

```java
Calendar cal = Calendar.getInstance();
Date d = new Date(cal.getTimeInMillis()); // Date(long date)
```

`Date -> Calendar`

```java
Date d = new Date();
Calendar cal = Calendar.getInstance()
cal.setTime(d);
```

`getInstance()`를 통해 얻은 인스턴스는, 기본적으로 현재 시스템의 날짜와 시간에 대한 정보가 담겨 있다.<br>
원하는 날짜나 시간으로 설정하려면 `set`메서드를 사용하면 된다.

`CalendarEx.java`예제에서는<br>
`int get(int field)`메서드를 이용해서 원하는 필드의 값을 얻어오는 방법을 알아보았다.

```java
public final static int YEAR = 1;
```

`get`메서드의 매개변수로 사용되는 `int`값들은 `Calendar`에 정의된 `static` 상수들이다.<br>
예제에서 자주 쓰이는 `Calendar` 상수들 위주로 `get`메서드를 통해 결과값을 알아보았다.

---

( `code/CalendarEx2.java` 예제 코드 참고 )

두 날짜간 차이를 구하는 예제로, `set`메서드를 통해 원하는 날짜로 값을 변경하였다.

```java
void set(int field, int value)
void set(int year, int month, int date)
void set(int year, int month, int date, int hourOfDay, int minute)
void set(int year, int month, int date, int hourOfDay, int minute, int second)
```

( `clear()`메서드를 사용하면 모든 필드의 값을, `clear(int field)`는 지정된 필드의 값을 기본값으로 초기화한다 )

시간상 차이를 알고 싶다면, 두 날짜간의 차이가 양수인지 음수인지를 판단하면 된다.<br>
간단히 `boolean after(Object when)`, `boolean before(Object when)`을 사용하여도 된다.
