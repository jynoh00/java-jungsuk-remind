# 11. parsing and format
> `java.time`패키지에서 배운 날짜와 시간을 원하는 형식(format)으로 출력하고, 해석(parsing)하는 법에 대하여

형식화(`formatting`)와 관련된 클래스들은 `java.time.format`패키지에 들어있으며,<br>
`DateTimeFormatter`클래스가 해당 포맷 패키지의 핵심이다.

`DateTimeFormatter`에는 자주 쓰이는 다양한 형식들을 기본적으로 정의하고 있고<br>
그 외의 형식이 필요하다면 직접 정의해서 사용이 가능하다.

```java
import java.time.format.DateTimeFormatter;

LocalDate date = LocalDate.of(2024, 1, 2);
String yyyymmdd =
        DateTimeFormatter.ISO_LOCAL_DATE.format(date);
String yyyymmdd2 = 
        date.format(DateTimeFormatter.ISO_LOCAL_DATE);
```

```java
static {
    ISO_LOCAL_DATE = new DateTimeFormatterBuilder()
            .appendValue(YEAR, 4, 10, SignStyle.EXCEEDS_PAD)
            .appendLiteral('-')
            .appendValue(MONTH_OF_YEAR, 2)
            .appendLiteral('-')
            .appendValue(DAY_OF_MONTH, 2)
            .toFormatter(ResolverStyle.STRICT, IsoChronology.INSTANCE);
}
```

날짜와 시간의 형식화에는 위처럼 `format()` 메서드를 활용하면 되는데<br>
`DateTimeFormatter`뿐 아니라 `LocalTime`, `LocalDate`같은 클래스에도 존재한다.

동일 기능을 하기에 상황에 따라 편한 쪽을 선택하여 사용하도록 한다.

---

`DateTimeFormatter`의 `static`메서드 `ofLocalizedDate()`, `ofLocalizedTime()`,<br>
`ofLocalizedDateTime()`은 모두 로케일(`locale`)에 종속적인 포맷터를 생성한다.

```java
DateTimeFormatter formatter = 
        DateTimeFormatter.ofLocalizedDate(FormatStyle.SHORT);

String shortFormat = formatter.format(LocalDate.now());
```

열거형 `FormatStyle`의 종류에 따른 출력 형태는 아래와 같다.

`FormatStyle : 날짜 : 시간`

- `FULL` : 2024년 12월 24일 화요일 : N/A
- `LONG` : 2024년 12월 24일 (화) : 오후 11시 22분 33초
- `MEDIUM` : 2024.12.24 : 오후 11:22:33
- `SHORT` : 24.12.24 : 오후 11:22

---

`DateTimeFormatter`의 `ofPattern()`으로 원하는 출력 형식을 직접 작성 가능하다.

```java
DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy/MM/dd");
```

출력 형식에 사용되는 자세한 기호 목록은 책 `p.603`을 참고한다.

---

문자열을 날짜와 시간으로 `파싱`하고 싶다면 `static`메서드 `parse()`를 활용한다.<br>
날짜와 시간을 표현하는데 사용되는 클래스에는 이 메서드가 거의 모두 포함되어 있다.

`parse()`는 오버로딩된 메서드가 여러 개 있는데, 그 중 다음 2개가 많이 활용된다.

```java
static LocalDateTime parse(CharSequence text)
static LocalDateTime parse(CharSequence text, DateTimeFormatter formatter)
```

이때 `DateTimeFormatter`에 상수로 정의된 형식을 사용하고자 할 때는 아래처럼 한다.

```java
LocalDate date = LocalDate.parse("2024-01-02", DateTimeFormatter.ISO_LOCAL_DATE);
```

자주 사용되는 기본적 형식의 문자열은 위와 같은 형식화 상수를 사용하지 않고도 파싱이 가능하다.

```java
LocalDate newDate = LocalDate.parse("2001-01-01");
LocalTime newTime = LocalDate.parse("23:59:59");
LocalDateTime newDateTime = LocalDateTime.parse("2001-01-01T23:59:59");
```
