# 05. java.time 패키지 1

`Date`와 `Calendar`가 가지고 있던 단점들을 해소하기 위해, `Java 8`부터 `java.time` 패키지가 추가되었다.

해당 패키지는 다음 4개의 하위 패키지로 구성된다.

`java.time` : 날짜와 시간을 다루는데 필요한 핵심 클래스들을 제공


- `java.time.chrono` : `표준(ISO)이 아닌` 달력 시스템을 위한 클래스들을 제공
- `java.time.format` : 날짜와 시간을 `파싱`하고, `형식화`하기 위한 클래스들을 제공
- `java.time.temporal` : 날짜와 시간의 필드(`field`)와 단위(`unit`)를 위한 클래스들을 제공
- `java.time.zone` : 시간대(`time-zone`)와 관련된 클래스들을 제공

위의 패키지들에 속한 클래스들의 가장 큰 특징은, `String`클래스처럼 불변(`immutable`)이라는 것이다.<br>
따라서 날짜나 시간을 변경하는 메서드들은 항상 새로운 객체를 반환한다.

⭐ 반면 기존 `Calendar`클래스는 변경이 가능하기에, `멀티 쓰레드 환경`에서 안전하지 못하다.

멀티 쓰레드 환경에서는 동시에 여러 쓰레드가 동일 객체에 접근할 수 있기에<br>
⭐ 변경 가능한 객체는 데이터가 잘못될 가능성이 있으며, 이를 쓰레드에 안전(`thread-safe`)하지 않다고 한다.

`java.time`패키지가 도입되었음에도, 앞으로도 기존 작성된 프로그램과의 호환성 때문에<br>
`Date`, `Calendar` 클래스들은 여전히 사용될 것이다.

( 이에 기존 날짜와 시간 관련 클래스들과 `java.time`패키지의 클래스와 변환 방법에 대해 알아야 한다, 후반부 )

---

### 1. java.time 패키지의 핵심 클래스

`java.time` 패키지에서는 날짜와 시간을 별도의 클래스로 분리해 놓았다.

시간을 표현할 때는 `LocalTime`클래스를, 날짜를 표현할 때는 `LocalDate`클래스를 사용한다.<br>
날짜와 시간이 모두 필요할 때는, `LocalDateTime`클래스를 사용한다.

추가로 시간대(`time-zone`)까지 다뤄야 한다면, `ZonedDateTime`클래스를 사용한다.

- `LocalTime` : 시간
- `LocalDate` : 날짜
- `LocalTime` + `LocalDate` = `LocalDateTime` : 시간 & 날짜
- `LocalDateTime` + 시간대 = `ZonedDateTime` : 시간 & 날짜 & 시간대

`Calendar`클래스는 `ZonedDateTime`클래스처럼 날짜, 시간, 시간대까지 모두 가지고 있다.

`Date`클래스와 유사한 클래스로는 `Instant`가 있는데, 해당 클래스는 날짜와 시간을 초 단위(나노 초)로 표현한다.<br>

날짜와 시간을 초단위로 표현한 값을 타임스탬프(`time-stamp`)라 하며<br>
이 값은 날짜와 시간을 하나의 정수로 표현할 수 있기에 날짜와 시간의<br>
`차이를 계산하거나`, `순서를 비교`하는데 유리하여 데이터베이스에 많이 사용된다.

외에도 `Year`, `YearMonth`, `MonthDay` 클래스 등이 있다.

---

#### 날짜 - 날짜 = Period

`Period`클래스는 날짜의 간격을 표현하기 위한 클래스로<br>
두 날짜간의 차이를 표현하기 위한 것이며

#### 시간 - 시간 = Duration

`Duration`클래스는 두 시간의 차이를 표현하기 위해 사용된다.

---

`java.time` 패키지에 속한 클래스의 객체를 생성하는 방법은 `now()`, `of()` 메서드를 사용하는 것이다.

`now()`는 현재 날짜와 시간을 저장하는 객체를 생성한다.

```java
LocalDate date = LocalDate.now();
LocalTime time = LocalTime.now();
LocalDateTime dateTIme = LocalDateTime.now();
ZonedDateTime dateTimeInKr = ZonedDateTime.now();
```

`of()`는 단순히 해당 필드의 값을 순서대로 지정해주면 된다.<br>
클래스마다 다양한 종류의 `of()`가 정의되어 있다.

```java
LocalDate date = LocalDate.of(2024, 12, 31);
LocalTime time = LocalTime.of(23, 59, 59);
LocalDateTime dateTime = LocalDateTime.of(date, time);
ZonedDateTime zDateTime = ZonedDateTime.of(dateTime, ZonId.of("Asia/Seoul"));
```

( `now()`와 `of()`는 `Calendar`클래스의 `getInstance()`처럼 팩토리 메서드이다 )

---

`LocalDate`, `LocalTime`, `LocalDateTime`, `ZonedDateTime` 등 날짜와 시간을 위한 클래스들은

- 모두 `Temporal`, `TemporalAccessor`, `TemporalAdjuster` 인터페이스를 구현하였고

`Duration`, `Period`는 `TemporalAmount` 인터페이스를 구현하였다.

⭐ 앞으로 소개할 메서드 중 매개변수의 타입이 `Temporal`로 시작하는 것들은, 대부분 날짜와 시간을 위한 것이므로<br>
⭐ `TemporalAmount`인지 아닌지만 확인하면 된다.

---

`TemporalUnit`, `TemporalField`

- 날짜와 시간의 `단위`를 정의해 놓은 것이 `TemporalUnit` 인터페이스이며<br>
`TemporalUnit`인터페이스를 구현한 것이 열거형 `ChronoUnit`이다.


- `TemporalField`는 년, 월, 일 등 날짜와 시간의 `필드`를 정의해 인터페이스로<br>
열거형 `ChronoField`가 이 인터페이스를 구현하였다.

( 열거형(`enumeration`)은 서로 관련된 상수를 묶어서 정의해 놓은 것으로 `ch11`에서 배우게 된다 )

```java
LocalTime now = LocalTime.now();
int minute1 = now.getMinute();
int minute2 = now.get(ChronoField.MINUTE_OF_HOUR);
```

`minute1`과 `minute2`는 동일한 값을 가진다.

날짜와 시간에서 특정 필드의 값만 얻고자 할 때는 `get()`이나 `get`으로 시작하는 메서드를 이용한다.

또한 아래처럼 특정 날짜와 시간에서 지정된 단위의 값을 더하거나 뺄 때는<br>
`plus()`, `minus()`에 값과 함께 열거형 `ChronoUnit`을 사용한다.

```java
LocalDate today = LocalDate.now();
LocalDate tomorrow1 = today.plus(1, ChronoUnit.DAYS);
LocalDate tomorrow2 = today.plusDays(1); // tomorrow1과 동일
```

`get()`과 `plus()` 메서드의 정의는 아래와 같다.

```java
int get(TemporalField field) // Temporal에 정의
LocalDate plus(long amountToAdd, TemporalUnit unit) // TemporalAccessor에 정의
```

자세한 내용은 추후 `LocalDate`, `LocalTime`에서 다룬다.
