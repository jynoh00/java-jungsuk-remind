# 07. java.time 패키지 3

### `with()`, `plus()`, `minus()`

`LocalDate`, `LocalTime`에서 특정 필드 값을 변경하려면 `with`로 시작하는 메서드를 활용한다.

```java
LocalDate withYear(int year)
LocalDate withMonth(int month)
LocalDate withDayOfMonth(int dayOfMonth)
LocalDate withDayOfYear(int dayOfYear)

LocalTime withHour(int hour)
LocalTime withMinute(int minute)
LocalTime withSecond(int second)
LocalTime withNano(int nanoOfSecond)
```

`with()`를 사용하면 직접 필드를 지정할 수 있다, 위 메서드들은 아래 `with()` 메서드로 구현되어 있다.

```java
LocalDate with(TemporalField field, long newValue)
```

필드를 변경하는 메서드들은 항상 새로운 객체를 생성해서 반환한다 배웠다.<br>
따라서 항상 대입 연산자를 같이 사용해야 한다.

```java
date = date.withYear(2024);
time = time.withHour(24);
```

---

값을 더하거나 빼는 `plus()`, `minus()` 메서드가 있는데

```java
LocalTime plus(TemporalAmount amountToAdd)
LocalTime plus(long amountToAdd, TemporalUnit unit)

LocalDate plus(TemporalAmount amountToAdd)
LocalDate plus(long amountToAdd, TemporalUnit unit)
```

이를 통해 만든 다양한 메서드들 또한 존재한다.

---

`LocalTime`의 경우 `truncatedTo()`를 통해 지정된 것보다 작은 단위의 필드를 `0`으로 만들 수 있다.

```java
LocalTime time = LocalTime.of(12, 34, 56);
time = time.truncatedTo(ChronoUnit.HOURS); // 시보다 작은 단위를 0으로
System.out.println(time); // 12:00
```

`LocalDate`에는 `truncatedTo()`가 없는데. `LocalDate`의 필드인 년, 월, 일은 0이 될 수 없기 때문이다.

`truncatedTo()`메서드의 매개변수는 책 `표 10-6`(열거형 `ChronoUnit`)에서<br>
시간과 관련된 필드만 사용가능하다.
