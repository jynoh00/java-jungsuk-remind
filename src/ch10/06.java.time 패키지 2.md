# 06. java.time 패키지 2

### LocalDate, LocalTime 클래스

`LocalDate`, `LocalTime`dms `java.time`패키지의 가장 기본이 되는 클래스로<br>
나머지는 이들의 확장이기에 두 클래스만 잘 이해하면 나머지는 쉽게 배울 수 있다.

```java
LocalDate today = LocalDate.now();
LocalDate now = LocalTime.now();

LocalDate birthDate = LocalDate.of(1999, 12, 31);
LocalDate birthTime = LocalTime.of(23, 59, 59);
```

`now()`, `of()` `static`메서드를 통해 `LocalDate`, `LocalTime` 객체를 생성한다.

`of()`메서드는 다음처럼 여러 버젼이 제공된다.

```java
static LocalDate of(int year, Month month, int dayOfMonth)
static LocalDate of(int year, int month, int dayOfMonth)

static LocalTime of(int hour, int min)
static LocalTime of(int hour, int min, int sec)
static LocalTime of(int hour, int min, int sec, int nanoOfSecond)
```

---

추가로 일 단위나 초 단위로도 객체를 생성할 수 있다.

```java
LocalDate birthDate = LocalDate.ofYearDay(1999, 365); // 1999년의 365번째 날, 1999년 12월 31일
LocalTime birthTime = LocalTime.ofSecondDay(86399); // 0시0분0초부터 86399초가 지난 시간, 23시 59분 59초
```

`parse`메서드를 통해 문자열을 날짜와 시간으로 파싱할 수도 있다. (추후 자세한 설명 예정)

```java
LocalDate birthDate = LocalDate.parse("1999-12-31");
LocalTime birthTime = LocalTime.parse("23:59:59");
```

---

`LocalDate`, `LocalTime` 객체에서 특정 필드의 값을 가져올 때 아래 메서드를 이용한다.

`1999년 12월 31일 23:59:59` 기준으로 각 메서드의 결과는 다음과 같다.

### LocalDate 메서드

- `int getYear()` : 1999 // 년도
- `int getMonthValue()` : 12 // 월 (1~12, Calendar는 0~11)
- `Month getMonth()` : 월(DECEMBER) getMonth().getValue() = 12
- `int getDayOfMonth()` : 31 // 일
- `int getDayOfYear()` : 365 // 1월 1일부터 몇번째 일
- `DayOfWeek getDayOfWeek()` : 요일(FRIDAY) getDayOfWeek().getValue() = 5
- `int lengthOfMonth()` : 31 // 같은 달의 총 일수
- `int lengthOfYear()` : 365 // 같은 해의 총 일수, 윤년이면 366
- `boolean isLeapYear()` : false // 윤년 여부

### LocalTime 메서드

- `int getHour()` : 23 // 시
- `int getMinute()` : 59 // 분
- `int getSecond()` : 59 // 초
- `int getNano()` : 0 // 나노초

---

이외에도 `get()`, `getLong()`이 있는데 원하는 필드를 직접 지정할 수 있다.<br>
대부분의 필드는 `int` 범위에 속하지만, 몇 필드는 `int`타입의 범위를 넘을 수 있어 `getLong()`을 사용한다.

```java
int get(TemporalField field)
int getLong(TemporalField field)
```

`get()`, `getLong()`의 매개변수로 사용할 수 있는 필드의 목록은 아래와 같다.

- ERA : 시대
- YEAR_OF_ERA, YEAR : 년
- MONTH_OF_YEAR : 월
- DAY_OF_WEEK : 요일 (1:월요일 ~ 7:일요일)
- DAY_OF_MONTH : 일
- AMPM_OF_DAY : 오전/오후
- HOUR_OF_DAY : 시간 (0~23)
- CLOCK_HOUR_OF_DAY : 시간 (1~24)
- HOUR_OF_AMPM : 시간 (0~11)
- CLOCK_HOUR_OF_AMPM : (1~12)
- MINUTE_OF_HOUR : 분
- SECOND_OF_MINUTE : 초
- MILLI_OF_SECOND : 10^-3분의 일초
- MICRO_OF_SECOND : 10^-6분의 일초 `getLong()`
- NANO_OF_SECOND : 10^-9분의 일초 `getLong()`
- DAY_OF_YEAR : 그 해의 몇번째 날
- EPOCH_DAY : EPOCH(1970.1.1)부터 몇번째 날 `getLong()`
- MINUTE_OF_DAY : 그 날의 몇 번째 분 (시간을 분으로 환산)
- SECOND_OF_DAY : 그 날의 몇 번째 초 (시간을 초로 환산)
- MILLI_OF_DAY : 그날의 몇 번째 밀리초
- MICRO_OF_DAY : 그날의 몇 번째 마이크로초 `getLong()`
- NANO_OF_DAY : 그날의 몇 번째 나노초 `getLong()`
- ALIGNED_WEEK_OF_MONTH : 그 달의 n번째 주 (1~7:1주, 8~14:2주, ...)
- ALIGNED_WEEK_OF_YEAR : 그 해의 n번째 주
- ALIGNED_WEEK_OF_WEEK_IN_MONTH : 요일 (그 달의 1일을 월요일로 간주하여 계산)
- ALIGNED_DAY_OF_WEEK_IN_YEAR : 요일 (그 해의 1월 1일을 월요일로 간주하여 계산)
- INSTANT_SECONDS : 년월일를 초단위로 환산 (1970-01-01 00:00:00 UTC를 0초로 계산), `Instant만`
- OFFSET_SECONDS : UTC와의 시차 `ZoneOffSet만`
- PROLEPTIC_MONTH : 년월을 월단위로 환산 (2015년11월 -> 2015*12+11)

( 해당 클래스가 지원하지 않는 필드를 매개변수로 하면, `UnsupportedTemporalTypeException`이 발생한다 )

특정 필드가 가질 수 있는 값의 범위는 아래처럼 알 수 있다.

```java
System.out.println(ChronoField.CLOCK_HOUR_OF_DAY.range()); // 1 - 24
System.out.println(ChronoField.HOUR_OF_DAY.range()); // 0 - 23
```
