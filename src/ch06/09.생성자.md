# 09. 생성자

생성자는 `인스턴스 초기화 메서드`이다.<br>
연산자 `new`가 인스턴스를 생성하는 것이지 생성자가 인스턴스를 생성하는 것이 아님에 유의한다.

---

생성자에서는 오버로딩된 다른 생성자를 호출할 수 있다.

```java
Car(String color) {
    door = 5;
    Car(color, "auto", 4);
}
```

위 코드는 `두 가지 에러가 발생`한다.

- 생성자의 두번 째 줄에서 다른 생성자를 호출
- this()를 통한 호출이 아닌 클래스 명을 사용하였음

생성자의 이름은 클래스 이름 대신 `this`를 사용해 호출해야 하며,<br>
⭐ 다른 생성자를 호출할 때는 반드시 첫 줄에서만 호출이 가능하다.

생성자 내에서 초기화 작업 중 다른 생성자를 호출할 경우, 호출된 다른 생성자가 멤버변수들의 값을<br>
초기화 하는 과정에서 이전 초기화 작업을 무의미하게 만들 수 있기에 에러가 발생하도록 정의한 것이다.

---

동일 클래스 내 생성자들은 일반적으로 서로 관계가 깊어 서로 호출할 수 있도록 하면<br>
코드의 중복을 줄이고 더 좋은 코드를 얻을 수 있다.<br>
수정이 필요한 경우에도 보다 적게 변경하면 되기에 유지보수가 쉬워진다.

// `this`는 참조변수이며, 인스턴스 자신의 주소를 가리킨다.<br>
// `this`를 사용할 수 있는 것은 인스턴스 멤버 뿐이다. (당연하다)

```java
class MyTestClass {
    int age;
    String name;

    MyTestClass(int age, String name) {
        this.age = age;
        this.name = name;
    }

//    MyTestClass(MyTestClass mtc) {
//        this.age = mtc.age;
//        this.name = mtc.name;
//    }

    // enhanced, 좀 더 간결하게
    MyTestClass(MyTestClass mtc) {
        this(mtc.age, mtc.name);
    }
}

public class Constructor2 {
    public static void main(String[] args) {
        MyTestClass myTestClass1 = new MyTestClass(1, "John");
        MyTestClass myTestClass2 = new MyTestClass(myTestClass1);

        System.out.println(myTestClass2.age);
        System.out.println(myTestClass2.name);

    }
}
```
