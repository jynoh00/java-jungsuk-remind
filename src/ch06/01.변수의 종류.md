# 01. 변수의 종류

변수는 클래스 변수, 인스턴스 변수, 지역 변수 모두 세 종류가 존재한다.<br>
변수의 종류를 결정짓는 중요 요소는 선언된 위치이며, 종류를 파악하기 위해서는 어느 영역에서 선언되었는지 확인해야한다.

자바에서 영역은 클래스 영역과 메서드 영역 두가지 뿐이며, 멤버 중 `static`이 붙은 것은 클래스 멤버이고, 붙지 않은 것은 인스턴스 멤버이다.<br>
인스턴스 변수와 클래스 변수의 타입으로는 추론 타입(`var`)이 사용 불가하다.

```java
public class MyClass {
    int iv; // 인스턴스 변수
    static int cv; // 클래스 변수

    void method() {
        int lv = 0; // 지역 변수
    }
}
```

변수의 종류에 따른 생성 시기는 아래와 같다.

- 클래스 변수 : 클래스가 메모리에 올라갈 때 (로딩될 때)
- 인스턴스 변수 : 인스턴스가 생성될 때
- 지역 변수 : 변수 선언문이 수행될 때
