# 10. 변수의 초기화

멤버 변수는 초기화 하지 않아도 자동적으로 자료형에 맞는 기본값으로 초기화된다.<br>
하지만 지역변수는 사용하기 전 반드시 초기화를 해야한다.

⭐ 인스턴스 변수와 클래스 변수는 초기화가 필수가 아니기에, 타입 추론(`var`)을 허용하지 않는다.

멤버 변수와 배열의 초기화는 선택이지만, 지역 변수의 초기화는 필수이다.

---

멤버 변수를 초기화 하는 방법으론 다음 세 가지 방식이 존재한다.

1. 명시적 초기화 (explicit initialization)

```java
class Car {
    int door = 4;
    Engine e = new Engine();
}
```

2. 생성자 (constructor)

`09.생성자.md` 참고

3. 초기화 블럭 (initialization block)
- 인스턴스 초기화 블럭 : 인스턴스 변수 초기화
- 클래스 초기화 블럭 : 클래스 변수 초기화

```java
class InitBlock {
    static { } // 클래스 초기화 블럭

    { } // 인스턴스 초기화 블럭
}
```

---

클래스 초기화 블럭은 클래스가 메모리에 처음 로딩될 때 한 번만 수행된다.<br>
인스턴스 초기화 블럭은 생성자처럼 인스턴스를 생성할 때마다 수행된다.

⭐ 생성자보다 인스턴스 초기화 블럭이 먼저 수행된다.

클래스가 처음 로딩될 때 클래스 변수들이 자동적으로 메모리에 만들어지고<br>
곧바로 클래스 초기화 블럭이 클래스 변수들을 초기화한다.

---

다음 예시를 통해 인스턴스 초기화 블럭의 유용성을 확인할 수 있다.

```java
Car() {
    count++;
    serialNo = count;
    colkor = "white";
    gearType = "Auto";
}

Car(String color, String gearType) {
    count++;
    serialNo = count; // 중복
    this.color = color; // 중복
    this.gearType = gearType;
}
```

```java
public class Car {
    {
        count++;
        serialNo = count;
    }
    
    ... // count++, serialNo = count 부분을 제외한 생성자들
}
```

인스턴스 초기화 블럭을 이용해 생성자들간 중복을 제거할 수 있는 것이다.<br>

`Car` 클래스의 `count`는 전체 객체 수를 나타내는 `static` 변수이다.<br>
그럼에도 인스턴스 초기화 블럭 내에서 값을 수정해도 괜찮을까?

-> 초기화 블럭은 실행 순서 관점에서 보아야한다. 인스턴스 초기화 블럭은 객체 생성마다 실행되는데,<br>
클래스 초기화 블럭은 처음 메모리에 로딩될 때 한번만 실행되기 때문이다. 

---

멤버변수의 `초기화 시기`와 `순서`는 다음과 같다.

`초기화 시점`
- 클래스 변수 : 첫 로딩 시점 단 한번 초기화
- 인스턴스 변수 : 생성될 때마다 각 인스턴스별로 초기화

`초기화 순서`
- 클래스 변수 : 기본값 -> 명시적 초기화 -> 클래스 초기화 블럭
- 인스턴스 변수 : 기본값 -> 명시적 초기화 -> 인스턴스 초기화 블럭 -> 생성자

```java
/**
 * 클래스 초기화 블럭은 처음 메모리에 로딩될 때 한번만 수행
 * 인스턴스 초기화 블럭은 생성될 때마다
 */
public class BlockEx {
    static {
        System.out.println("BlockEx static{}");
    }

    {
        System.out.println("BlockEx {}");
    }

    public BlockEx() {
        System.out.println("Constructor");
    }

    public static void main(String[] args) {
        System.out.println("main");
        BlockEx be = new BlockEx();
        BlockEx be2 = new BlockEx();
    }
}

```
