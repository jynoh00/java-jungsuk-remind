# 07. 오버로딩

다음 예시를 통해 오버로딩을 진행함에 있어 유의해야 하는 내용에 대해 복기해보겠다.

```java
public class OverLoading {
    static long add(int a, long b) {
        System.out.println("add1");
        return a + b;
    }
    
    static long add(long a, int b) {
        System.out.println("add2");
        return a + b;
    }
    
    public static void main(String[] args) {
//        System.out.println(add(3, 4));
        // error
        System.out.println(add(3, 4L));
        System.out.println(add(3L, 4));
    }
}
```

위 코드를 컴파일 해보면 어떠한 오류도 없이 정상 작동한다. 정상적으로 오버로딩된 것이다.<br>
그러나 주석처리한 부분인

```java
System.out.println(add(3, 4));
```

해당 내용을 해제할 경우 컴파일 에러가 발생한다.<br>
그러한 이유는 `add(3,4)`와 같이 호출할 경우 매개변수에 `int`타입인 `3`, `4`를 대입하는 과정에서<br>
두 오버로드된 메서드 모두 `int` 타입을 `long`타입에 대입이 가능하기에 모호성을 가져 컴파일 에러가 발생하는 것이다.
