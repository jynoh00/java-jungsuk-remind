# 03. 기본형 매개변수

메서드를 호출할 경우 매개변수로 지정한 값은 매개변수에 복사해서 넘겨주는 것이다.<br>
매개변수의 타입이 기본형일 때는 기본형 값이 복사되지만

```java
public class PrimitiveParamEx {
    public static void main(String[] args) {
        Data d = new Data();
        d.x = 10;
        System.out.println("main(): " + d.x);
        change(d.x);
        System.out.println("main(): " + d.x);
    }

    private static void change(int x) {
        x = 1000;
        System.out.println("change(d.x): " + x);
    }
}
```

참조형일 경우 인스턴스의 주소가 복사된다.<br>
즉 값이 저장된 주소를 넘겨주는 것이기에, 원본 인스턴스의 데이터를 변경하는 것 또한 가능하다.

```java
class ReferenceParamEx {
    public static void main(String[] args) {
        Data d = new Data();
        d.x = 10;
        System.out.println("main(): " + d.x);
        change(d);
        System.out.println("main(): " + d.x);
    }

    private static void change(Data d) {
        d.x = 1000;
        System.out.println("change(d.x): " + d.x);
    }
}
```
