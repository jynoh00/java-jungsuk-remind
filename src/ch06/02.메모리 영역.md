# 02. 메모리 영역

자바 프로그램이 실행될 경우 JVM은 시스템으로부터 프로그램을 수행하는데 필요한 메모리를 할당받고<br>
해당 메모리를 용도에 따라 여러 영역으로 나누어 관리한다. 그 중 3가지 주요 영역에 대해 알아보겠다.

`method area` , `heap` , `call stack`

---

1. 메서드 영역 (method area)

프로그램 실행 중 어떤 클래스가 필요한 경우, JVM은 해당 클래스의 클래스 파일을 읽어서 분석하여<br>
클래스에 대한 정보(클래스 데이터)를 메서드 영역에 저장한다. 이때 해당 클래스의 클래스 변수(`static` 선언)도 이 영역에 함께 생성된다.

---

2. 힙 (heap)

인스턴스가 생성되는 공간으로 프로그램 실행 중에 인스턴스는 힙 영역에 생성된다.<br>
즉 인스턴스 변수가 생성되는 공간으로, 연산자 `new`를 통해 새로운 메모리를 생성하기에 `heap` 영역에 위치하는 것이다.

---

3. 호출 스택 (call back or execution stack)

호출 스택은 메서드의 작업에 필요한 메모리 공간을 제공하는 곳으로<br>
메서드가 호출되면, 호출 스택에 호출된 메서드를 위한 메모리가 할당된다.<br>
해당 메모리는 메서드가 작업을 수행하는 동안 지역 변수와 연산의 결과를 저장하는 용도로 사용된다.<br>
또한 메서드가 종료되면 할당되었던 메모리 공간은 자동으로 반환된다. 이름에서 알 수 있는 것처럼 `stack`의 자료구조 방식(`LIFO`)을 가진다.

```java
public class CallStackEx {
    public static void main(String[] args) {
        firstMethod();
    }

    private static void firstMethod() {
        secondMethod();
    }

    private static void secondMethod() {
        System.out.println("secondMethod()");
    }
}
```
