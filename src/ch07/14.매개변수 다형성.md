# 14. 매개변수 다형성
> 앞서 살펴 본 참조변수의 다형적 특징은 메서드의 매개변수에도 적용된다. 

아래 클래스들을 예로 살펴보겠다.

```java
class Product {
    int price;
    int bonusPoint;
}

class Tv extends Product {}
class Computer extends Product {}
class Audio extends Product {}

class Buyer {
    int money = 1000;
    int bonusPoint = 0;
}
```

`Buyer` 클래스에 물품을 구매하는 기능을 메서드로 추가하여보고자 할 때 구매할 제품이 필요하므로<br>
매개변수로 제품을 넘겨받아야 한다. `Tv`를 살 수 있도록 매개변수를 `Tv` 타입으로 하면

```java
void buy(Tv t) {
    money = money - t.price;
    bonusPoint = bonusPoint + t.bonusPoint;
}
```

위와 같이 `Tv`로 매개변수의 타입을 지정할 경우, `Computer`, `Audio`와 같은 객체는<br>
`buy()` 메서드로 해결할 수 없어 추가 메서드 작성이 필요하다.

이를 매개변수의 다형성을 통해 아래와 같이 하나의 메서드로 처리할 수 있다

```java
void buy(Product p) {
    money = money - t.price;
    bonusPoint = bonusPoint + t.bonusPoint;
}
```

매개 변수가 `Product` 타입 참조변수이기에 메서드의 매개변수는 `Product`의 자손 타입 참조변수면<br>
어느 것이나 매개변수로 받아들일 수 있다는 의미이다.

---

매개변수의 다형성을 살펴보기 위해 또 다른 예인 `PrintStream`에 정의되어 있는<br>
`print(Object obj)` 메서드를 살펴보면

매개변수로 `Objecct`타입의 변수가 선언되어 있는데, `Object`는 모든 클래스의 조상이므로<br>
해당 메서드의 매개변수로 어떤 타입의 인스턴스도 가능하기에 이 하나의 메서드로 모든 타입의 인스턴스를 처리할 수 있는 것이다.

해당 메서드는 매개변수에 `toString()`을 호출하여 문자열을 얻어 출력한다. 아래는 실제 코드이다.

```java
// PrintStream 클래스의 메서드
public void print(Object obj) {
    write(String.valueOf(obj));
}

// String 클래스의 메서드
public static String valueOf(Object obj) {
    return (obj == null) ? "null" : obj.toString();
}
```
