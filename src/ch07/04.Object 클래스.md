# 04. Object 클래스

`Object` 클래스는 상속 계층도의 최상위에 있는 조상클래스이다. 다른 클래스로부터 상속 받지 않는<br>
모든 클래스들은 자동적으로 `Object`클래스로부터 상속받게 함으로써 이를 가능하게 한다.

```java
class Tv {
    ...
}
```

위 코드를 컴파일하면 컴파일러는 위 코드를 다음과 같이 자동적으로 추가하여 `Object` 클래스를 상속받도록 한다.<br>
(이미 어떤 클래스로부터 상속받도록 작성된 클래스는 `extends Obeject`를 추가하지 않는다.)

```java
class Tv extends Object {
    ...
}
```

결과적으로 `Object`클래스는 모든 클래스의 조상이 된다. 다른 클래스를 상속 받는다 하더라도<br>
상속계층도를 따라 조상, 조상의 조상을 찾아 올라가다 보면 결국 마지막 조상은 `Object`클래스이다.  

---

모든 상속 계층도의 최상위에는 `Object`클래스가 있기에, 자바의 모든 클래스는<br>
`Ojbect`클래스의 멤버들을 상속 받기 때문에 `Object`클래스에 정의된 멤버들을 사용할 수 있다.

`toString()`이나 `equals(Object o)`와 같은 메서드를 따로 정의하지 않고 사용할 수 있는 이유가<br>
해당 메서드들이 `Object`클래스에 정의되었기 때문이다.
