# 03. 단일 상속

`C++`언어에서는 여러 조상 클래스로부터 상속받는 다중 상속을 허용하지만,<br>
`Java`에서는 단일 상속만 허용한다.

다중 상속을 허용할 경우 여러 클래스로부터 상속받을 수 있기에 복합적인 기능을 가진 클래스를<br>
쉽게 작성할 수 있다는 장점이 있지만, 클래스간 관계가 매우 복잡해진다는 것과<br>
⭐ 서로 다른 클래스로부터 상속받은 멤버간의 이름이 같은 경우 구별할 수 있는 방법이 없다는 단점을 가진다.

```java
class TvDVD extends Tv, DVD {} // error
```

---

이렇듯 자바는 다중 상속을 허용하지 않기에 상속과, 참조변수를 이용하여 기능하도록 사용할 수 있다.

```java
class TvDVD extends Tv {
    DVD dvd = new DVD();
    ...
}

```
