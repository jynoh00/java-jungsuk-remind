# 11. instanceof
> `instanceof` 연산자는 `참조 변수가 참조하고 있는 인스턴스`의 실제 타입을 알아보기 위해 사용한다.

```java
public class InstanceofEx {
    public static void main(String[] args) {
        FireEngine fe = new FireEngine();
        Car c = new Car();

        if (fe instanceof FireEngine) System.out.println("True1");
        if (fe instanceof Car) System.out.println("True2");
        if (fe instanceof Object) System.out.println("True3");
        if (c instanceof Car) System.out.println("True4");

        if (c instanceof FireEngine) System.out.println("True5");
    }
}

class Car {}
class FireEngine extends Car {}
```

`True1` ~ `True4`까지 모두 출력되며, `True5`의 경우 출력이 되지 않는다.

이를 통해 생성된 인스턴스의 `instanceof` 연산을 수행할 경우 실제 인스턴스와 같은 타입의 `instanceof` 연산외에도<br>
조상 타입의 `instanceof` 연산에도 `true`를 결과로 얻으며

⭐ `instanceof` 연산의 결과가 `true`라는 것은 검사한 타입으로의 형변환을 해도 문제가 없다는 뜻이다.

```java
System.out.println(fe.getClass().getName()); // FireEngine 출력
```

`.getClass().getName()`은 참조변수가 가리키는 인스턴스의 클래스 이름을 문자열로 반환한다.

---

`instanceof`는 `참조변수의 형변환`과 함께 사용되기에<br>
`instanceof` 다음에 오는 형변환을 생략할 수 있는 문법이 추가되었다.

- 기존 방식

```java
if (c instanceof FireEngine) {
    FireEngine fe = (Fireengine) c;
    fe.water();
    ...
}
```

- 패턴매칭

```java
if (c instanceof FireEngine fe) {
    fe.water();
    ...    
}
```

패턴매칭 방식에서 참조변수 `fe`는 `if`문 블럭 내에 선언된 지역 변수이기에 블럭 밖에서는 사용이 불가하다.<br>
그러나 다음의 경우 예외적으로 블럭 밖에서도 사용이 가능하다.

```java
if (!(obj instanceof Point p)) {
    return false;
}
// Point p = (Point) obj;
return x == p.x && y == p.y;
```

주석처리한 부분이 필요가 없게 되는 것이다. 추가적으로 아래처럼 `if`문 내에서 지역변수이자 참조변수인<br>
`p`를 바로 조건식으로 사용할 수 있다.

```java
if (obj instanceof Point p && x == p.x && y == p.y) {
    ...    
} 
```

이와 같은 `instanceof` 패턴 매칭과 조건식을 결합이 가능한 경우는 `&&` 연산자로 할 때만 가능하다.<br>
`||`연산자의 경우 조건식을 결합할 수 없다.<br>
`&&`연산자와 달리 `||`연산자는 왼쪽 피연산자가 `false`이어도 오른쪽 피연산자를 평가하기 때문이다.

```java
if (obj instanceof Point p || x == p.x) { // error
    ...
```

---

아래는 `x, y` 좌표를 멤버로 가지는 `Point2D` 클래스의 인스턴스간 동일성을 판단하는 멤버 메서드를<br>
`instanceof`의 다양한 모습으로 작성한 코드이다. 모두 기능은 동일하다.

```java
public boolean equals(Object obj) {
    if (!(obj instanceof Point2D p)) {
        return false;
    }

    return x == p.x && y == p.y;
}

public boolean equals2(Object obj) {
    return obj instanceof Point2D p && x == p.x && y == p.y;
}

public boolean equals3(Object obj) {
    if (!(obj instanceof Point2D)) return false;

    Point2D p = (Point2D) obj;
    return x == p.x && y == p.y;
}
```
