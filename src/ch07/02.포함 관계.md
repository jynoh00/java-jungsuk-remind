# 02. 포함 관계

상속 이외에도 클래스 간에 관계를 맺어줄 수 있는 방법이 있다.<br>
클래스 간에 `포함`관계를 맺어주는 것으로 이를 구현하는데

```java
class Point {
    int x, y;
}

class Circle {
    Point c = new Point();
    int r;
}
```

위 코드를 통해 `Circle` 클래스의 멤버로 `Point` 인스턴스를 생성하여<br>
참조변수 `c`를 통해 재사용하는 것을 알 수 있다.

---

클래스를 작성함에 있어 서로간의 관계를 파악하고 바르게 이어주는 것이 중요하다.<br>
이를 위해선 다음의 방법을 사용하면 전체는 아니지만 대다수의 관계를 해결할 수 있다.

```java
class Circle1 {
    Point c = new Point();
    int r;
}

class Circle2 extends Point {
    int r;
}
```

`Circle1`방식은 참조 변수를 선언하여 포함 관계를<br>
`Circle2`는 상속을 통해 관계를 맺어주어 기능상으론 별 차이가 없어 보인다.

- Circle은 Point이다. (`is a`)
- Circle은 Point을 가지고 있다. (`has a`)

원은 원점과 반지름으로 구성되므로 위 두 문장을 비교하였을 때<br>
두 번째 문장이 옳다는 것을 알 수 있다.

따라서 `is a`처럼 연결될 경우 상속으로, `has a`로 연결될 경우 포함 관계로<br>
맺어주는 것이 대다수의 문제를 해결할 수 있다.
