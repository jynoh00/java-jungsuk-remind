# 15. 다양한 객체 배열
> 조상 타입의 참조 변수 배열을 사용하면, 공통 조상을 가진 서로 다른 종류의 객체를 배열로 묶어 다룰 수 있다.

```java
Product[] p = new Product[3];

p[0] = new Tv();
p[1] = new Computer();
p[2] = new Audio();
```

*참고*

배열의 정적 크기가 문제가 될 경우, `C++`에서와 비슷한 `Vector` 클래스를 활용하면 된다.<br>
자바에서의 `Vector` 클래스 역시 동적으로 크기가 관리되는 배열이다.

- `Vector()`
  - 10개의 객체를 저장할 수 있는 `Vector` 인스턴스를 생성한다.
  - 10개 이상의 인스턴스가 저장되면 자동적으로 크기가 증가한다.
- `boolean add(Object o)`
  - `Vector`에 객체를 추가한다.
  - 추가에 성공하면 `true`, 실패하면 `false`를 반환한다.
- `boolean remove(Object o)`
  - `Vector`에 저장되어 있는 객체를 제거한다.
  - 성공하면 `true`, 실패하면 `false`를 반환한다.
- `boolean isEmpty()`
  - `Vector`가 비어있는지 검사한다.
  - 비어있으면 `true`, 아니라면 `false`를 반환한다.
- `Object get(int index)`
  - 지정된 위치(`index`)의 객체를 반환한다.
  - 반환 타입이 `Object`이기에 적절한 타입의 형변환이 필요하다.
- `int size()`
  - `Vector`에 저장된 객체의 개수를 반환한다.

---

해당 부분을 학습하며 가장 먼저 다음과 같은 의문이 떠올랐다.

*1. 조상타입의 참조변수로 배열을 만들고 자손 객체를 배열에 넣으면, 조상 타입으로 형변환이 이루어진다.*<br>
*2. 그럴 경우 만든 배열을 통해 자손 객체에 접근하면*<br>
*3. 조상 타입으로 변환된 객체이기에 자손객체에만 있는 멤버가 사용 불가하게 되는 것 아닌가?*

이를 확인하고자 책의 예제(`예제7-25/PolyParamEx3.java`) 중 `Tv` 클래스에 다음과 같은 메서드를 추가하였다.

```java
public void tvMethod() {
    System.out.println("test Tv Method");
}
```

이후 `main` 메서드에서 `Product` 클래스에는 없는 `Tv` 클래스의 메서드 두개를 실행한 결과

```java
System.out.println(b.items[0].toString()); // Tv
b.items[0].tvMethod(); // error
```

`toString()` 메서드는 정상적으로 실행되나, `tvMethod()`는 에러가 발생하였다.<br>
`tvMethod()`가 실행되지 않은 이유는 앞서 생각했던 본인의 생각과 일치했다.

그렇다면 `toString()` 메서드는 어떻게 실행된 것일까?

`toString()`은 자바에서 최상위 조상 클래스인 `Object`에서 정의되어 있는 메서드로<br>
이를 `Tv` 클래스에서 오버라이딩한 것이기에 `b.items[0]`이 참조하는 실제 객체인 `Tv`의 메서드가 실행된 것이다.

이를 `동적 바인딩`(`Dynamic Binding`)이라 한다.

그렇다면 조상 타입의 참조변수로 선언한 배열에서 자손 객체의 멤버에 접근하고 싶으면 어떻게 할까?

이는 형변환을 통해서 구현 가능하다. 실제 객체는 자손 객체이기에, 자손 타입으로 재형변환이 가능한 것이다.

```java
(Tv)b.items[0].tvMethod(); // error
((Tv)b.items[0]).tvMethod(); // test Tv Method
```

이때 주의할 점은 위 코드에서 첫 줄과 같이 작성할 경우<br>
연산자 우선순위에 의하여 `b.items[0].tvMethod()`가 먼저 수행되고 앞선 이유와 동일하게 에러가 발생한다.

따라서 `((Tv)b.items[0])`처럼 괄호로 우선순위를 확실하게 하여야 한다.

해당 부분에서 직접 작성한 전체 코드는 책과 조금씩 다르기에 `code/PolyParamEx.java`으로 올려두었다.
