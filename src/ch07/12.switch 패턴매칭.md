# 12. switch 패턴매칭
> `JDK 21`부터 `switch`문의 조건식으로 참조형도 가능하게 확장되었다. 

12장에서 배울 `열거형`과 `레코드` 등의 새로운 기능과 함께 사용되어 코드를 더 간결하게 작성할 수 있도록 도와준다.

```java
double getArea(Shape s) {
    double area = 0.0d;
    if (s instanceof Rectangle r) area = r.getWidth() * r.getHeight();
    else if (s instanceof Triangle t) area = t.getWidth() * t.getHeight() * 0.5;
    else if (s instanceof Circle c) area = c.getRadius() * c.getRadius() * Math.PI;
    else area = -1.0;

    return area;
}
```

위와 같은 예제를 `switch식`으로 작성하여 다음과 같이 간략화할 수 있다.

```java
double getArea(Shape s) {
    return switch(s) {
        case Rectange r -> r.getWidth() * r.getHeight();
        case Triangle t -> t.getWidth() * t.getHeight() * 0.5;
        case Circle c -> c.getRadius() * c.getRadius() * Math.PI;
        default -> -1.0; // 그 외 모든 case 처리, 단 s가 null인 경우는 포함x
    };
}
```

이때 `switch식`의 조건식이 참조 변수일 때 가능한 모든 경우의 수(`null` 제외)를 처리해야 한다.<br>
`Shape` 클래스의 자손은 얼마든지 새로 추가될 수 있기에 `default`가 반드시 필요하다.

(이후 배우게 될 실드 클래스`sealed class`는 자손의 개수를 제한할 수 있기에 `default`가 필수가 아니다 )

⭐ (`switch문`과 달리 `switch식`은 어떤 경우에도 값을 반환해야 한다 )

---

`switch식`은 조건식의 참조변수가 `null`인 경우, 실행 중에 에러(`NullPointerException`)가 발생한다.

⭐ `default`는 참조변수가 `null`인 경우를 처리하지 않는다는 점을 주의해야 한다.

`JDK 21`부터는 다음과 같이 `null`을 처리하는 `case`를 추가하는 것이 가능해졌다.<br>
`null`처리 `case`가 존재하면 실행 중에 에러가 발생하지 않는다.

```java
return switch(s) {
    case null -> 0; // default보다 위에 놓아야 한다.
        ...
};
```

---

`case`의 순서 또한 `switch식`을 작성할 때 주의하여야 한다.

```java
class Product {}
class Tv extends Product {}
class CaptionTv extends Tv {}
class SmartTv extends Tv {}
```

위와 같이 상속 관계를 가지는 4개의 클래스를 선언하였을 때<br>
제품을 구입하는 `buy()` 메서드는 다음과 같이 작성할 수 있는데, 이때 `case`의 순서에 주의해야 한다.

```java
void buy(Product p) {
    bonus += switch(p) {
        case CaptionTv c -> 120;
        case Tv t -> 100;
        case SmartTv s -> 200; // error
        ...
        default -> 0;
    };
}
```

`case`는 첫 번째 부터 내려오며 절차적으로 평가하기에 `Tv`타입의 `case`가 위에 있으면<br>
해당 `case`가 모든 종류의 `Tv`를 처리하므로 아래에 있는 `SmartTv`타입을 처리하는 `case`는 절대 실행될 수 없다.

따라서 두 케이스의 순서를 변경해주어야 한다.

---

⭐ `case` 안에 `if`문이 중첩된 경우 `case-when`으로 간결하고 명확하게 처리가 가능하다.

```java
String getString(String str) {
    return switch(str) {
        case null -> "null";
        case String s when s.isEmpty() -> "empty";
        case String s when s.isBlank() -> "blank";
        case String s -> "String";
    };
}
```

추가로 `null`을 처리하는 `case`와 `default`를 아래와 같이 하나로 합칠 수 있다.

```java
String type = switch(str) {
    case String s when s.isEmpty() -> "empty";
    case String s when s.isBlank() -> "blank";
    case null, default -> "null or default";
};
```

이때 이 `case`는 가장 마지막에 와야하며, `null`은 반드시 `default` 왼쪽에 놓아야 한다.
